# 직접 플레이해 보기

먼저 일반 조건으로 한 판 해 보고, 다음에 전체 카드·특기를 체험해 주세요. 승리보다 ‘무엇이 이해됐고 어디서 막혔는지’가 중요합니다.

## 실행

프로젝트 폴더에서 터미널을 열고 실행합니다.

```sh
npm run dev -- --host 127.0.0.1 --port 5199
```

브라우저에서 [일반 플레이](http://127.0.0.1:5199/?safe=1)를 엽니다. 끝나면 터미널에서 Ctrl+C로 서버를 끕니다. 처음에는 이름 입력과 브리핑이 나오고, 생활관 오른쪽 아래 ‘전투 투입’으로 시작합니다. 이미 입력했다면 생활관부터 열립니다. 초록 선은 화면 안전 영역 확인용이며 `safe=1`을 빼면 사라집니다.

검사는 세로390×844로 했습니다. 주소의 `localhost`와 `127.0.0.1`, 포트, 시크릿 창을 바꾸면 별도 저장으로 보일 수 있으니 같은 주소를 쓰세요. 아래 전체 해금 체험에서는 전투 결과/기록도 저장되므로 일반 진행을 보존하려면 **별도 시크릿 창**에서 여세요. 기본 창의 저장 데이터를 지울 필요는 없습니다.

## 첫 판

1. 상점에서 카드를 사고, 아래 대기석에서 판의 배치 구역으로 끌어 놓습니다.
2. 같은 보직·계급 두 장을 겹치면 진급합니다. 일병이 되면 A/B 특기를 고릅니다.
3. 준비가 되면 ‘전투 투입!’을 누릅니다. 필요할 때 좌상단 일시정지와 화력 지원을 사용합니다.
4. 결과에서 ‘다시 투입’ 또는 ‘생활관’으로 이동합니다. 일반 플레이에서 웨이브5에 도달할 때마다 다음 보직이 한 종씩 해금됩니다.

일반 판에는 추가 보급·갓모드·전체 해금을 넣지 않습니다. 한 판 시간은 이름/브리핑 이후 전투 투입부터 결과까지 대략 재 주세요. 일시정지나 중단이 길었다면 같이 적어 주세요.

## 새 카드와 특기 체험

별도 시크릿 창에서 [전체 해금·새4종 상병A 체험](http://127.0.0.1:5199/?scene=walk&unlock=all&supply=99&seed=7&safe=1&deck=medic:1,signal:1,mortar:1,antitank:1&rank=3&spec=A)을 엽니다. 상점은10종 전체 해금, 시작 보급99, 새4종은 상병A로 지급됩니다. 이 네 카드를 대기석에서 꺼내 배치해야 능력이 작동합니다. **추가 보급을 쓴 체험 결과를 일반 난이도 기록과 구분**해 주세요.

같은 주소 끝의 `spec=A`를 `spec=B`로 바꾸면 다른 특기, `rank=3`을 `rank=4`로 바꾸면 병장을 체험합니다. A/B를 바꿀 때는 새 주소로 다시 열어 한 판을 시작합니다.

| 카드 | 확인할 느낌 |
|---|---|
| 의무병 | 인접 아군이 쓰러졌을 때 소생할 시간이 있는가? 응급처치(A)와 피해 감소(B)가 다르게 느껴지는가? |
| 통신병 | 직접 공격 없이 옆 카드의 공격 간격을 줄이는 역할과 지원 횟수 보너스가 이해되는가? |
| 박격포병 | 너무 가까운 적을 못 쏘는 이유와 예고된 지점에 뒤늦게 떨어지는 공격이 보이는가? 고폭(A)/취약(B)의 차이가 보이는가? |
| 대전차병 | 큰 적·강화 군견 상대의 역할이 보이는가? 철갑(A)/연속(B) 중 어느 쪽을 고를 이유가 있는가? |

현재 `scene=battle`로 바로 연 전투는 결과에서 생활관으로 돌아가지 못하는 문제가 발견됐습니다. 위 생활관 경유 링크를 사용하세요. 막혔다면 새로고침해 새 판을 시작할 수 있습니다.
