## 한 장 요약

- **사용자가 원하는 것**: 자대 배치 첫날 데프콘 2 → 위병소 돌파. 보직 카드(소총수·취사병·화학병·제설병·지뢰설치병·저격수)를 배치하고, 준비 시간에 대비하고, 자동 전투로 웨이브를 막는 세로형 카드 디펜스. 짬 성장, 시너지. 나중에 포병(FDC·탄약 운반병·포수)·전차·드론·대공. 구글 플레이 먼저, 보상형 광고와 광고 시청 해금.
- **Gemini 수정본**: 스코프를 줄이고(5병과 MVP), 데프콘 단계별 웨이브 연출, 포병은 스킬 버튼으로, 화생방은 가스 장판으로 줄이자는 안. 에셋 규격(마젠타 배경, 상태별 프레임).
- **ChatGPT 수정본**: 성장 축은 하나, 시너지 규칙은 적게, 수익은 검증할 가설, 민감한 군사 정보는 재현하지 않기.
- **레퍼런스 공통 교훈**: 스탯 성장보다 수평 해금, 보상형 광고만(강제 광고는 Cat Gunner의 최대 불만), MVP는 도형으로 1~2주 안에 검증.
- **OSINT에서 쓸 것**: K14 저격소총, K30 비호·천호(대드론), K9A2 + K10 탄약보급장갑차 + K77 사격지휘장갑차(포병 3보직의 근거), 88식/98식 보총, M2020 전차(보스 후보), 회색지대 도발(오물 풍선·소형 무인기), 철원 혹한·장마·GOP 철책.
- **OSINT에 없는 것**(R-102가 조사): 취사병, 제설 장비, 화생방 탐지기, 지뢰 매설, 계급·은어·짬 문화, RPG·박격포, 생체개조 동물.
- **재현 금지**: 작전계획, 기동로, 화력 유도 절차, 시설 좌표, 주파수. 실제 부대마크·북한 견장·우상화 초상화는 변형한다.
