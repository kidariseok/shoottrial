# T-004 배달 로봇·방범 드론 + 웨이브 진행

상태: 대기
담당: Antigravity · gemini-4-argon-high

## 목표

`/?scene=battle&stage=1&wave=1`에서 스테이지 1의 웨이브 1~3이 `src/stages.ts`대로 진행된다(보스 제외).
- 배달 로봇: 달려와 붉은 `!` 0.4초 후 들이받는다.
- 방범 드론: 멈춰서 붉은 조준선 0.6초 후 탄을 쏜다.
- 웨이브의 적을 다 잡으면 다음 웨이브로 넘어간다.

## 할 일

1. **`data.ts`**: `ENEMIES.rusher`, `ENEMIES.shooter`(GDD §4.3), `LIMITS`(동시 활성 상한)
2. **`stages.ts`**: 스테이지 1 웨이브 1~3을 데이터로 적는다.
   - 형식: `{ at: 초, type, side: 'T'|'L'|'R'|'B', count, gap: 초 }[]`
   - 보스 자리는 비워 둔다(P3).
3. **`rules.ts`**
   - `scaleEnemy(base, stage)`: 스테이지 보정
   - `spawnSchedule(wave, seed)`: 시간순 스폰 목록. 같은 시드면 같은 결과
   - 둘 다 테스트를 추가한다.
4. **`enemies.ts`**: 적 그룹(`maxSize` = 상한)과 적 탄 그룹(최대 40)
   - 상태: `enter → chase → telegraph → attack → recover`. **클래스 계층 없이** 타입별 `switch`로 처리한다.
   - 예고 그래픽: 배달 로봇은 머리 위 `!`(크림슨), 드론은 플레이어까지 1px 크림슨 선 + 흰 심
   - 분리: 지상 적은 반경 12px 안의 다른 지상 적에게서 밀려난다(간단한 반발 벡터). 드론은 겹쳐도 된다.
   - 화면 밖 스폰: 웨이브 데이터의 `side`(`T`·`L`·`R`·`B`)에 따라 아레나 밖 그 변의 무작위 위치(시드 고정). 아레나 안에 들어올 때까지 경계 충돌을 끈다.
   - 배달 로봇: 60px 안에서 멈춤 → `!` + 돌진 방향 붉은 선 0.4초 → 그 방향으로 0.35초 돌진(방향은 예고 시작 때 고정) → 0.5초 쉼.
   - 방범 드론: 거리 140을 두고 플레이어 주위를 천천히 돈다 → 멈춤 → 조준선 0.6초 → 1발.
5. **웨이브 진행**(`BattleScene`)
   - 남은 적 0 → 1.5초 뒤 다음 웨이브
   - 웨이브 시작 40초 후에도 화면 밖에 남은 적은 화면 안으로 끌어온다.
   - 화면 위쪽(HUD 아래)에 "WAVE n" 텍스트를 1초간 띄운다(HUD는 T-005).
6. **피해 연결**
   - `player.ts`에 `hit(dmg)`를 추가한다. `invincible`이면 무시하고, 아니면 `hp`를 깎는다.
   - 접촉·적 탄 overlap을 등록한다. 시각 피드백은 T-005·T-006에서 붙인다.
   - `?god=1`이면 피해가 0이다.
