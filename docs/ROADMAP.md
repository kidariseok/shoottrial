### 게이트 통과 조건

| 게이트 | 조건 | 실패 시 |
|---|---|---|
| **G0** | 실기기(본인 폰)에서 ① 가로 고정 ② 풀스크린 ③ 우상단 금지 구역 비움(`?safe=1` 캡처) ④ 백버튼 → 확인 모달 ⑤ 저장한 숫자가 앱 재실행 후 유지 | ①이 안 되면 **세로형 재설계** 회의(Claude) |
| **G1** | 사용자 10판 + 지인 1명 3판. 터치 씹힘 0, 구르기·자동 사격이 "답답하지 않다", "한 판 더"에 예. Claude가 diff 리뷰 | 아트 투입 금지. 수치·조작 튜닝 티켓만 발행 |
| G2 | 스테이지 1 + 보스 완주(그림·소리 포함). 외부 3명. 흑백 가독성 검사 통과. 백그라운드 사운드 정지 확인 | 아트·피드백 수정 |
| G3 | 30분 세션 테스트. 5~7판에 스테이지 3 클리어. 카드 픽률이 한쪽으로 쏠리지 않음 | 밸런스 티켓 |
| G4 | `docs/TECH.md` §9 체크리스트를 실기기에서 100% + 등급분류·게임제작업 서류 준비 완료 | 수정 후 재검사 |

**행정 트랙(P0부터 병행, 사용자)**
1. 사업자등록
2. 게임제작업 등록(지자체)
3. 등급분류(R-002 결과에 따라 원스토어 웹게임 자체등급 또는 GRAC)
4. 콘솔 정산 정보

등급분류에는 플레이 가능한 빌드가 필요하므로 **P3이 끝나면 바로 신청**한다.

## 4. Claude Code(Claude Pro)를 쓰는 때

- **게이트마다 1회**: "G1 리뷰해줘"
  - 지난 태그부터의 diff, 티켓 결과 보고, 플레이 메모를 읽는다.
  - `docs/reviews/G1.md`를 작성하고 다음 단계 티켓을 발행한다.
- 막힌 질문 모음 처리: 티켓 `## 질문`이 쌓이면 한 번에 가져온다.
- 대사·문구 정리(C 티켓): ChatGPT 초안을 붙여 넣으면 톤을 맞춘다.
- 그 밖의 구현은 맡기지 않는다(사용량 절약 + 역할 분리).

## 5. 사용자의 하루 루틴

1. `docs/ROADMAP.md` §2에서 다음 티켓을 고른다(선행이 끝난 것).
2. Antigravity에서 **새 대화**를 열고 모델을 고른 뒤 `/start-ticket T-00X`를 입력한다.
3. 에이전트가 계획을 티켓에 쓰면 읽어 보고 "진행"이라고 답한다.
4. 끝나면 `docs/shots/T-00X.png`와 티켓의 결과 보고를 확인한다. 직접 `npm run dev` → 디버그 URL로 플레이해 본다.
5. 괜찮으면 다음 티켓으로 간다. 이상하면 같은 대화에서 고쳐 달라고 하거나, 티켓 `## 질문`에 적어 두었다가 게이트 때 Claude에게 가져온다.
6. 게이트 티켓(P-00X)이 끝나면 Claude Code에서 "G0 리뷰해줘"라고 요청한다.
