# 앱인토스 발행 안내 (T-123)

근거: 앱인토스 개발자센터 https://developers-apps-in-toss.toss.im/llms.txt (2026-10-31 확인). 정책은 수시로 바뀌니 제출 직전에 [게임 출시 가이드](https://developers-apps-in-toss.toss.im/checklist/app-game)를 다시 읽는다.

## 코드 쪽 (완료)

- `npm run build:toss` → `newbie-defense.ait`(프로젝트 루트, gitignore). 약 10MB(한도 100MB).
- `npm run dev:toss` → 토스 모드 개발 서버(샌드박스 앱 연결용). 토스 앱 밖 브라우저에서는 SDK 초기화가 실패하고 웹 체험판으로 폴백한다.
- 토스 SDK는 `src/platform.ts`에서만 쓴다. 토스 모드가 아닌 빌드(Vercel·안드로이드)에는 들어가지 않는다.
- 연결한 것: 뒤로가기(종료 확인 모달), Safe Area(+우측 상단 닫기 버튼 줄), 앱 단위 Storage 세이브, 사용자 식별키, 보상형 광고(`loadFullScreenAd`/`showFullScreenAd`, 보상은 `userEarnedReward`에서만).
- 광고 그룹 ID: 개발 중에는 테스트 ID(`ait-ad-test-rewarded-id`)가 기본이다. 운영 ID는 콘솔에서 발급받아 `.env.toss`에 `VITE_AIT_REWARDED_ID=...`로 둔다(`.env*`는 gitignore). **운영 ID로 개발 테스트하면 정책 위반이다.**
- `apps-in-toss.config.ts`의 `appName`은 콘솔 등록값과 같아야 한다. 현재 `newbie-defense`(2026-10-31 사용자 결정, 한글명 신병 디펜스).

## 사용자가 해야 할 일 (순서)

1. **콘솔 가입** https://apps-in-toss.toss.im/ — 만 19세 이상, 본인 명의 토스 앱 필요. 워크스페이스를 만들고 제작자 이름(10자 이내)을 정한다.
2. **앱 등록** — 유형 "게임", appName(영문, 등록 후 변경 불가)·앱 이름 결정. appName을 정하면 `apps-in-toss.config.ts`를 맞춘다.
3. **광고 그룹 만들기** — 콘솔 인앱 광고에서 보상형 그룹 ID 발급. 사업자 등록은 누적 광고 수익 5,000원 전까지 유예된다(이후 5영업일 안에 사업자·정산 등록, 안 하면 미노출).
4. **등급분류 (가장 큰 막힘)** — 게임은 등급 증빙이 필수다. 방법은 둘.
   - 게임물관리위원회(GRAC) 직접 신청: 플랫폼 "모바일", 스토어명 "기타-앱인토스", 접속 방식 "인터넷 접속". 약 10~15일, 수수료 있음(GRAC 모의 수수료 계산기).
   - 스토어 설문(IARC): 앱이 구글 플레이 등에 **실제로 출시된 URL**이 있어야 한다. 구글 콘솔을 미뤄 둔 지금은 불가.
5. **번들 업로드·테스트** — `npm run build:toss` → 콘솔에 `.ait` 업로드 → "토스앱 테스트" QR을 토스 앱으로 스캔. 최소 1회 테스트해야 검토 요청이 된다.
6. **앱 정보** — 부제, 상세 설명(디펜스 게임 흐름을 구체적으로), 로고 600×600 PNG(투명·둥근 모서리·사람 얼굴 불가), 썸네일 1932×828 PNG, 세로 스크린샷 636×1048 최소 3장(선택), 고객문의 이메일, 등급 정보.
7. **검토 요청** — 영업일 3~7일. 통과하면 "출시하기".

## QR 테스트 체크리스트 (이 환경에서는 못 한다)

- 10초 안에 첫 화면이 뜬다. 우측 상단 닫기(X)와 게임 UI가 겹치지 않는다(겹치면 `TOSS_CLOSE_BAND`를 조정).
- 안드로이드 뒤로가기 → 종료 확인 모달 → 확인하면 미니앱이 닫힌다. 모달이 이중으로 뜨지 않는다.
- 홈으로 나가면 소리가 즉시 멈추고 돌아오면 다시 난다. (WebView의 `visibilitychange`에 의존하므로 반드시 확인)
- 광고: 테스트 ID로 로드·재생·보상 지급, 닫으면 게임으로 복귀하고 소리가 돌아온다. 중도 이탈 시 보상 없음.
- 앱을 껐다 켜도 이름·해금·최고 기록이 유지된다.
- 화면 방향이 세로로 유지된다. 어긋나면 `Screen.setOrientation({ type: 'portrait' })`를 platform.ts에 추가한다.

## 알려진 한계·판단이 필요한 것

- 저장은 토스 앱 로컬이다. 토스 앱을 지우면 사라진다(식별키는 기기를 바꿔도 같지만 서버 저장은 없다). 기록 이전이 필요하면 서버 연동(별도 티켓)이 필요하다.
- 리더보드(`Game` 리더보드), 공유 리워드, 인앱 결제는 붙이지 않았다. 필요하면 후속 티켓.
- 현재 앱인토스는 만 19세 이상 사용자에게만 제공된다(콘솔 문서).
- 생성형 AI·허구 고지는 기존 로비 화면 문구를 그대로 쓴다. 심사에서 위치를 지적하면 조정한다.
- 이 환경에서 확인한 것: 타입체크, 389개 테스트, 에셋 검사, 웹/토스 빌드, `.ait` 생성, 토스 앱 밖 폴백. **토스 앱 안의 실제 동작은 확인하지 못했다.**
