## 할 일

1. **전투 화면 목업**(Figma, 새 프레임, 세로 9:16)
   - 위병소 배경(`6:36`) 위에 GDD §3 배치를 얹는다: 지뢰 구역 5×2, 배치 구역 5×3, 위병소 방어선, 대기석 5칸, 상점 패널
   - 기존 소총수(`5:18`) 2~3명, 기존 UI 패널(`6:33`)로 HUD·상점을 대충 배치한다. **새로 그리지 않는다**
   - 목적: 칸 크기(128)와 캐릭터 크기가 화면에서 읽히는지 눈으로 확인
2. **북한군 보병 기준 시트**(Gemini Argon, 마젠타 배경, 앞·뒤·옆): 북한군 물자 시트(`7:53`)와 기존 소총수 시트를 참조 이미지로 첨부한다. 견장은 실제와 다르게 변형한다
3. **소총수 뒷모습 사격** 2~4프레임: 전투 모션 시트(`5:18`)를 첨부하고 "same character, seen from behind, firing upward"로 생성한다
4. **계급장 4종**: 한국군식 가로 작대기 1~4개(이등병~병장). 기존 V자는 쓰지 않는다
5. 2~4번 결과 PNG를 `art/source/A-101/`에 넣는다. 프롬프트는 같은 이름의 `.txt`로 저장한다
6. Claude Code에 "A-101 끝났어"라고 알리면, Claude가 목업 스크린샷을 Figma에서 읽어 해상도를 확정하고 장부를 적는다
