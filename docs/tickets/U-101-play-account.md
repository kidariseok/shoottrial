# U-101 구글 플레이 개인 개발자 계정 + 패키지 이름 + 테스터 후보 모으기

상태: 대기
담당: 사용자

## 목표

- 구글 플레이 개인 개발자 계정이 만들어져 신원 확인까지 끝난다.
- 앱 패키지 이름이 정해진다.
- 비공개 테스트에 참여할 테스터 후보 **15명 이상**(12명 + 이탈 여유)의 명단이 **저장소 밖**에 모인다.

## 할 일

1. Play Console(play.google.com/console)에서 **개인** 계정으로 가입하고 등록비를 내고 신원 확인을 마친다.
2. **패키지 이름**을 정한다. 한 번 출시하면 바꿀 수 없다.
   - 예: `io.github.kidariseok.defcon2`, `com.<내 도메인>.defcon2`
   - 정한 값을 이 티켓 결과 보고에 적는다(T-101이 쓴다)
3. **테스터 후보 모으기**(M2 동안 계속)
   - 지인, 군 커뮤니티 등에서 **안드로이드 폰을 쓰는** 15명 이상
   - 구글 계정 이메일 명단은 **저장소에 넣지 않는다**(저장소가 공개다). 개인 메모나 구글 시트에 둔다
   - 14일 동안 앱을 지우지 않고 가끔 켜 달라고 미리 부탁한다
4. 게임제작업·사업자등록 등 행정은 R-101 결과를 보고 필요한 것만 한다.

## 완료 조건

- [ ] 계정 생성 + 신원 확인 완료
- [ ] 패키지 이름 확정(결과 보고에 적음)
- [ ] 테스터 후보 15명 이상(숫자만 결과 보고에 적음)
