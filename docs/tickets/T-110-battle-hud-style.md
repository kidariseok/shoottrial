# T-110 전투 화면 UI를 "야간 작전" 시안 A로

상태: 대기
담당: Antigravity · **Claude Sonnet 5.5 High** 또는 Gemini 최상위 모델(Argon 제외, 사고 수준 높음). 2번 막히면 다른 쪽으로 바꾼다.

## 목표

전투 화면이 "박스 나열"이 아니라 **입체적인 어두운 군용 장비판** 느낌이 된다(사용자 확정 시안 A).
- 하단 카드 칸에 **새 카드 그림(`card_*.png`)**이 들어간다. 지금은 글자뿐인 상자다.
- 상단 바, 버튼, 체력 막대, 시너지 표시가 금테·금속 질감으로 통일된다.
- 동작과 `screens.ts`의 함수 시그니처는 바뀌지 않는다. 겉모습만 바꾼다.

시안: https://claude.ai/artifact/8k9cK2wA5vW12taJjcQxU7 의 "A 야간 작전 · 전투"(`art/ref/ui-canvas/project/A-Battle.dc.html`).

## 용어(사용자 확정 2026-10-24)

적이 쳐들어오는 상황이라 "출동"을 쓰지 않는다. `screens.ts`의 문구를 다음처럼 바꾼다. 글자만 바꾸고 동작은 그대로다.
- 준비 단계 버튼 "출동!" → **"전투 투입!"**
- 결과 화면 "다시 출동" → **"다시 투입"**, 제목 "복귀 보고"가 있으면 **"전투 결과 보고"**
- 로비 쪽 문구는 T-109가 바꾼다.

## 디자인 기준(시안 A에서 옮긴다)

- 색: 바탕 `#0b0e12`, 판 `#1b2229`, 금 `#c9a24a`·`#e8c35a`, 경고 `#e0412f`, 전투 투입·초록 `#5d6b2a→#3f4a1c`. 토큰은 `:root` CSS 변수 한 곳에 모은다.
- 글꼴: 제목류는 굵은 한글 디스플레이(시안은 Black Han Sans), 본문은 Noto Sans KR. **둘 다 OFL**이라 파일을 `public/fonts/`에 넣어도 된다. 파일 크기는 합쳐서 1MB 이하, 필요한 굵기만. `assets:check`가 `public/fonts/`를 막으면 `## 질문`에 적고, 우선 시스템 굵은 글꼴로 끝낸다.
- 금테 + 안쪽 어두운 테두리(`box-shadow` 두 겹), 눌렀을 때 살짝 들어가는 느낌. 새 이미지를 만들지 않는다. 그림은 `card_*`만 쓴다.

## 할 일

1. **카드 칸**(하단 상점·대기석): 카드마다 `card_<키>.png`를 배경으로 깔고 위에 이름·보급 비용 배지·계급(작대기)·보직 머리글자를 얹는다.
   - 살 수 없으면 어둡게, 살 수 있으면 금테가 살짝 빛난다. 선택된 카드는 위로 떠오른다.
   - 사진이 없는 키는 지금의 단색 상자로 폴백한다(`?scene=gallery`로 확인).
   - **카드를 눌러도 시안의 레이아웃·동작(드래그·길게 눌러 정보)은 그대로**다.
2. **상단 바**: 일시정지(왼쪽 위, 위치 유지) · 웨이브 칩 · 데프콘 배지 · 속도 버튼을 금속 판 위에 정리한다. 보급은 아이콘 + 숫자, 위병소 HP는 체력 막대(위험하면 붉게).
3. **시너지 표시**: 켜진 시너지는 금색 칩, 꺼진 건 회색 칩.
4. **버튼 3종**: "전투 투입!"(초록 + 금테, 좁으면 "투입!"), 화력 지원(경고색, 남은 횟수 배지, `support`가 없거나 0이면 비활성), 보조(리롤·판매·일시정지)는 어두운 판 + 금 글자.
5. **모달·결과 화면**: 같은 판·금테·글꼴로 맞춘다. 문구는 그대로이되 아래 "용어"만 바꾼다.
6. 모든 UI는 **Safe Area 안**, 390×844와 360×800에서 잘리지 않는다(`?safe=1`로 확인).
7. 테스트: 새 순수 함수가 생기면 `tests/ui.test.ts`에. (예: 카드 비용 대비 보급으로 "살 수 있음" 판정은 이미 있으면 재사용.)
