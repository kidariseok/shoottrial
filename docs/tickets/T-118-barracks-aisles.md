## 할 일

1. 좌우 침상 줄 전체를 막던 사각형을 침대·관물대·바구니별로 분리한다.
2. 침상 사이 가로 통로를 열고 그 안 관물대 접근점을 배치한다.
3. 동료를 중앙 길 밖 침상/관물대 앞으로 옮기고 별도 길막 충돌을 제거한다.
4. 생성 방식 승인 후 기존 인물 외형을 유지한 앉은 자세를 제작·저장하고 Figma에 배치한다. 앞서 지시한 이미지 선승인은 유지한다.
5. 그림 승인 후 가공·연결하고 실제 키보드/조이스틱으로 통로/관물대/대화/전투 왕복을 검증한다.

## 작업 계획

1. walk.ts 좌표 표에서 실제 침대8개·관물대·소품의 발 주변만 막는다. 좁은 통로에 맞춰 발 충돌 반경을 줄인다.
2. 관물대 접근점을 침상 사이로 옮기고 두 NPC는 침상 쪽에 배치한다. 가구 충돌과 별도로 NPC가 길을 막지 않게 한다.
3. 사용자 생성 방식 선택 후 참조 기반 앉은 두 캐릭터 시안을 제작한다. 얼굴만 좌/정면/우를 향하는3프레임, 몸은 침상에 앉은 고정 자세를 계획한다. Figma 승인 전 게임에 새 그림을 반영하지 않는다.
4. 승인 후 투명·128캔버스·발 기준선·장당512KB 이하 처리/장부, 대화 시 고개 방향 연결. verify 및 실제 입력 증거·PR.
