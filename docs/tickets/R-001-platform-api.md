## 할 일

아래 항목마다 표 한 줄(이름 / import / 시그니처 / 최소 버전 / 주의점 / 출처 URL / 확인일)을 쓴다. 문서에서 찾지 못한 것은 "문서 없음"으로 적는다. **추측으로 채우지 않는다.**

1. **화면**
   - 화면 방향: 세로가 기본인지, 기기를 돌려도 세로로 고정하는 방법(설정 파일 옵션 또는 런타임 함수)
   - 풀스크린·투명 내비게이션 바 설정
   - iOS 스와이프 뒤로가기 끄기
   - 화면 꺼짐 방지
   - WebView 바운스·당겨서 새로고침 끄기 옵션
2. **Safe Area**: 값 얻기·구독. 우측 상단 시스템 버튼(더보기·닫기)의 크기·위치에 대한 공식 수치가 있으면 함께 적는다.
3. **앱 이벤트**
   - 안드로이드 백버튼 이벤트 구독
   - 미니앱 닫기
   - 백그라운드·포그라운드 전환 이벤트(웹 `visibilitychange` 외에 SDK 이벤트가 있는지)
4. **사용자 식별키**(게임용)
5. **Storage**: get/set/remove, 값 크기 제한, 브라우저(devtools)에서의 동작
6. **햅틱**: 함수, 지원 타입 목록
7. **게임 리더보드**: 점수 제출, 리더보드 열기, 최소 버전, 주의사항(열 때 앱이 백그라운드가 되는지 등)
8. **보상형 광고**
   - load/show 함수와 지원 여부 확인 함수
   - **이벤트 이름 전체 목록**(보상 획득, 닫힘, 실패 등)
   - 테스트용 광고 ID
   - 알려진 OS·앱 버전별 이슈
   - 정책상 문구 제한
9. **분석 로그**: 함수, 이벤트 이름·파라미터 제한
10. **로컬 테스트**: SDK 3.x devtools가 무엇을 흉내 내는지(위 1~9 중 어떤 것이 브라우저에서 동작하는지), 설치·실행 방법
11. **빌드·배포**
    - `.ait` 만드는 명령
    - `apps-in-toss.config.ts` 필수 필드
    - 콘솔 업로드
    - QR(또는 푸시)로 실기기 테스트하는 순서
12. **게임 심사 관련**: 게임 카테고리 콘솔 이미지 규격(로고·썸네일·스크린샷)
