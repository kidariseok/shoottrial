## 할 일

1. `Unit`에 `spec?: 'A' | 'B'` 추가. 같은 카드·계급2장 합성, 이름 상속·판매 환급·대기석 가득 찬 구매 연쇄 합성은 유지한다. 일병 진급 시 선택, 같은 특기끼리 진급하면 유지, 다른 특기끼리 합성하면 다시 선택한다. 선택 완료 전 다음 연쇄 합성을 진행하지 않아 중간 선택이 유실되지 않게 한다. 다른 특기의 상병끼리 병장 합성할 때도 재선택하며, 드래그 대상 이름 우선·구매 시 배치 우선 생존칸과 이름 상속은 유지한다.
2. 준비 단계의 특기 선택 모달에 두 설명을 나란히 표시한다. 선택 중 게임시간·카드 드래그·상점·전투 투입을 잠근다. 전투 중 선택 방식은 아래 기획 질문의 답변으로 확정한다. 뒤로가기·일시정지·씬 종료에서 중복 콜백이나 미선택 상태의 전투 시작을 막는다. 선택 흐름은 DOM 경계 함수를 통해 연결하고 TECH §8 계약을 먼저 갱신한다.
3. 아래 기존6종 수치만 `src/data.ts`의 표에 모으고 계산은 `src/rules.ts` 순수 함수로 둔다. HP/공격 계급배율×1.5는 누적하며 상병·병장 능력도 누적한다. 특기별 계산·경계·중첩을 GDD 표와1:1로 검사한다.

| 카드 | 특기 A | 특기 B | 상병 | 병장 |
|---|---|---|---|---|
| 소총수 | 사수: 사거리+1.5칸, 간격×1.15 | 돌격: 사거리−1칸, 간격×0.75, 1.5칸 안 피해×1.3 | 2점사 | 간격−20% |
| 저격수 | 정밀: 첫 명중 피해×1.5 | 관통: 폭0.4→0.8칸, 감쇠−20%→−10% | 관통 감쇠 없음 | 첫 명중1초 기절 |
| 제설병 | 방벽: HP×1.2, 받는 피해−10%→−25%, 도발1.5→2.5칸 | 돌풍: 밀어내기×1.5, 취약2→3.5초, 간격×0.8 | 밀어낸 적3초간 초당8 화상 | 밀어내기2칸 |
| 취사병 | 영양: 회복12→18 | 보급: 웨이브 종료 보급+1 | HP비율 낮은2명 동시 회복 | 회복 범위2칸 |
| 지뢰설치병 | 다량 매설: 토큰+1 | 부비트랩: 폭발 범위 적1초 기절 | 보스·장갑 피해×3 대전차 지뢰 | 토큰+2 |
| 화학병 | 제독: 제독 범위+1칸, 간격3→2초 | 화생방 사격: 직접 공격에3초 중독(초당4) | 제독 범위2칸 | 인접 아군 직접 공격+15% |

4. 기존 코드의 취사병 상병 소생·전원 회복 등 GDD와 달라진 부분을 이번 규칙에 맞춘다. 소생은 의무병 전담이므로 취사병에서 제거한다. 취사병 시너지2명은 전원 회복, 그렇지 않을 때 이등병/일병1명·상병/병장2명이다. 지뢰의 기절/대전차 속성은 생산자 특기와 함께 묻힌 지뢰까지 전달하고, 중독은 직접 공격으로만 부여한다.
5. 계급 성장은 발 기준선과 드래그 칸 크기를 유지해 몸·이펙트로 표현한다. 몸 배율은 T-111의 매프레임 모션 배율과 함께 곱하고, 계급 장식·정보 표시가 `motion=0`에서 사라지지 않도록 한다. 일병 링, 상병 금빛 후광·크기×1.1, 병장 별 오라·크기×1.2·폭죽·말년 칭호. T-111 `promoteMotion`과 A-105 경례를 사용하고 진급 대사는1.5초 말풍선으로 표시한다. 기존6종 이름·소개·진급 대사18개는 GDD 표 그대로 data.ts에 둔다. 소총수 이름은 플레이어 이름을 상속한다.
6. 카드 정보창에 인물·소개·계급·특기·실제 수치·능력을 표시한다. 정보가 없는 기존 호출도 동작하도록 호환성을 유지한다. 피격/진급 콜백의 판 유효성을 확인하고, 전투 중 저장은 추가하지 않는다(TECH §5, 현재 persist.ts는 판 기록용이므로 Unit 저장을 새로 만들지 않음).
7. 디버그 URL로 특기 선택·서로 다른 특기 합성·일병/상병/병장 성장을 재현하고 스크린샷과 실행한 검증 결과를 남긴다. 서버·브라우저는 확인 뒤 종료한다.

### 디버그 계약(예정)

- `?scene=battle&wave=3&unlock=all&supply=99&seed=7&safe=1&deck=rifle:2,sniper:2&rank=2&spec=A`: 지급 덱에 지정 계급과 특기를 적용해 일병A 상태를 바로 확인한다. 기본 신병은 그대로 이등병이다.
- 같은 URL의 `&rank=3&spec=B`, `&rank=4&spec=A`로 상병/병장과 특기를 비교한다. rank는1~4, spec은A/B만 허용한다. 기존 debug URL에 새 항목이 없으면 기존 동작을 유지한다.
- `?scene=battle&unlock=all&supply=99&seed=7&deck=rifle:2`로 같은 이등병2장을 합쳐 실제 선택 모달을 확인한다. 다른 특기 합성과 대기석 포화 연쇄는 동일 debug 배치와 실제 보드/상점 동작으로 재현한다.
- 새 디버그 필드는 `src/debug.ts`에서 해석하고 덱 지급 옵션으로 전달한다. 게임 수치와 보상 로직은 바꾸지 않는다.

### UI/보드 계약(검토 반영, 구현 전 TECH §8 갱신)

- 기존 `shop`6개 인자와 `BattleCtl` 필수 메서드는 유지한다.
- `chooseSpecialty(request: { card: string; rank: number; name?: string } | null, onPick?: (spec: 'A' | 'B') => void): void` 신설. null/종료 때 콜백을 실행하지 않고 폐기하며 선택 버튼은1회 실행 뒤 잠근다.
- `cardInfo(card: string | null, rank?: number, detail?: { name?: string; spec?: 'A' | 'B'; rows?: [string,string][] }): void`로 선택적 세 번째 인자만 추가해 기존 두 인자 호출을 유지한다. 실제 계산 수치 행은 A에서 넘기고 DOM은 계산을 복제하지 않는다.
- 구매 성공 때 상점 칸·비용을1회 확정하고 최초 순수 구매 계획을 한 단계씩 이어간다. 선택 중에는 다음 승급을 실행하지 않으며 전체 연쇄가 끝나기 전 잠금을 풀지 않는다.
- 선택 대기와 `paused`는 구분한다. `board.lock`은 진행 중 카드/지뢰 드래그 원복·길게누르기 취소·강조 제거까지 다룬다. `buy/reroll/go/startFight`·광고 보상 진입도 잠금을 확인한다.
- 선택 중 뒤로가기는 일시정지를 위에 열고, 계속하면 선택으로 돌아간다. 포기/씬 종료는 대기 continuation을 폐기한다. 새 판에 옛 선택 콜백이 적용되지 않게 판/대상 유효성을 검사한다.
- 계급 장식은 몸 앞의 첫 두 자식에 끼워 넣지 않는다(T-111 도형 폴백이 첫 두 자식을 몸으로 묶음). 바깥 view 크기/히트 영역은 유지하고 발 피벗의 몸 성장만 적용한다. 말년은 원본 name을 바꾸지 않고 화면에서 붙인다.

### 계산·경계의 기본 결정(검토 반영)

- 지뢰 토큰은 기본 [1,2,3,4] + 병장2 + A1이며, 단독 병장B6/A7이다. 기존의6개를 중복 계상 오류로 줄이지 않는다. 각 생산자의 `{anti,stun}` 토큰을 배열에 담고 묻을 때 속성을 복사한다. 시너지 추가1개는 일반 토큰으로 정해 출처가 없는 추가 보너스를 임의 중첩하지 않는다. 이미 묻힌 지뢰는 생산자 판매/진급이나 다음 웨이브에 바뀌지 않는다.
- 취사병 B는 클리어 정산 때 배치된 보급 특기 취사병1명당+1, 대기석 제외, 쓰러진 아군 포함(정산 복귀 규칙). 클리어마다1회이며 마지막 승리 웨이브에도 가산하고 패배/포기에는 가산하지 않는다.
- 제설병 A HP 배율은 최초 HP·짬밥 최대HP·웨이브 복귀 모두에 적용한다. 도발2.5칸은 일반1.5칸 필터 밖에서도 작동해야 한다. 화상은 최초로 실제 밀어낸 적에만 기존 규칙대로 부여한다.
- 저격 관통 피해는 기존 선형 감쇠를 유지한다. 독은 화상과 별도 타이머이며 재명중 때 시간 갱신·비중첩, 남은 시간보다 큰 dt는 남은 시간만 피해를 준다. 병장 화학병 직접 공격 버프를 독·화상·지뢰에 다시 곱하지 않는다.
- 화학병 즉시 제독은 이미 가스가 남은 칸에 재낙하해도 최종 값0이어야 한다. 제독 주기는 직접 사격 간격과 분리한다.
- 신규4종·새 저장 시스템·전반적 광고 리팩터링은 추가하지 않는다.
