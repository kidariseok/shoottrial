## 할 일

1. `Unit`에 `spec?: 'A' | 'B'` 추가. 같은 카드·계급2장 합성, 이름 상속·판매 환급·대기석 가득 찬 구매 연쇄 합성은 유지한다. 일병 진급 시 선택, 같은 특기끼리 진급하면 유지, 다른 특기끼리 합성하면 다시 선택한다. 선택 완료 전 다음 연쇄 합성을 진행하지 않아 중간 선택이 유실되지 않게 한다.
2. 준비 단계의 특기 선택 모달에 두 설명을 나란히 표시한다. 선택 중 준비시간·카드 드래그·상점·전투 투입을 잠근다. 뒤로가기·일시정지·씬 종료에서 중복 콜백이나 미선택 상태의 전투 시작을 막는다. 선택 흐름은 DOM 경계 함수를 통해 연결하고 TECH §8 계약을 먼저 갱신한다.
3. 아래 기존6종 수치만 `src/data.ts`의 표에 모으고 계산은 `src/rules.ts` 순수 함수로 둔다. HP/공격 계급배율×1.5는 누적하며 상병·병장 능력도 누적한다. 특기별 계산·경계·중첩을 GDD 표와1:1로 검사한다.

| 카드 | 특기 A | 특기 B | 상병 | 병장 |
|---|---|---|---|---|
| 소총수 | 사수: 사거리+1.5칸, 간격×1.15 | 돌격: 사거리−1칸, 간격×0.75, 1.5칸 안 피해×1.3 | 2점사 | 간격−20% |
| 저격수 | 정밀: 첫 명중 피해×1.5 | 관통: 폭0.4→0.8칸, 감쇠−20%→−10% | 관통 감쇠 없음 | 첫 명중1초 기절 |
| 제설병 | 방벽: HP×1.2, 받는 피해−10%→−25%, 도발1.5→2.5칸 | 돌풍: 밀어내기×1.5, 취약2→3.5초, 간격×0.8 | 밀어낸 적3초간 초당8 화상 | 밀어내기2칸 |
| 취사병 | 영양: 회복12→18 | 보급: 웨이브 종료 보급+1 | HP비율 낮은2명 동시 회복 | 회복 범위2칸 |
| 지뢰설치병 | 다량 매설: 토큰+1 | 부비트랩: 폭발 범위 적1초 기절 | 보스·장갑 피해×3 대전차 지뢰 | 토큰+2 |
| 화학병 | 제독: 제독 범위+1칸, 간격3→2초 | 화생방 사격: 직접 공격에3초 중독(초당4) | 제독 범위2칸 | 인접 아군 직접 공격+15% |

4. 기존 코드의 취사병 상병 소생·전원 회복 등 GDD와 달라진 부분을 이번 규칙에 맞춘다. 소생은 의무병 전담이므로 취사병에서 제거한다. 취사병 시너지2명은 전원 회복, 그렇지 않을 때 이등병/일병1명·상병/병장2명이다. 지뢰의 기절/대전차 속성은 생산자 특기와 함께 묻힌 지뢰까지 전달하고, 중독은 직접 공격으로만 부여한다.
5. 계급 성장은 발 기준선과 드래그 칸 크기를 유지해 몸·이펙트로 표현한다. 몸 배율은 T-111의 매프레임 모션 배율과 함께 곱하고, 계급 장식·정보 표시가 `motion=0`에서 사라지지 않도록 한다. 일병 링, 상병 금빛 후광·크기×1.1, 병장 별 오라·크기×1.2·폭죽·말년 칭호. T-111 `promoteMotion`과 A-105 경례를 사용하고 진급 대사는1.5초 말풍선으로 표시한다. 기존6종 이름·소개·진급 대사18개는 GDD 표 그대로 data.ts에 둔다. 소총수 이름은 플레이어 이름을 상속한다.
6. 카드 정보창에 인물·소개·계급·특기·실제 수치·능력을 표시한다. 정보가 없는 기존 호출도 동작하도록 호환성을 유지한다. 전투 중 저장은 추가하지 않는다(TECH §5, 현재 persist.ts는 판 기록용이므로 Unit 저장을 새로 만들지 않음).
7. 디버그 URL로 특기 선택·서로 다른 특기 합성·일병/상병/병장 성장을 재현하고 스크린샷과 실행한 검증 결과를 남긴다. 서버·브라우저는 확인 뒤 종료한다.

### 디버그 계약(예정)

- `?scene=battle&wave=3&unlock=all&supply=99&seed=7&safe=1&deck=rifle:2,sniper:2&rank=2&spec=A`: 지급 덱에 지정 계급과 특기를 적용해 일병A 상태를 바로 확인한다. 기본 신병은 그대로 이등병이다.
- 같은 URL의 `&rank=3&spec=B`, `&rank=4&spec=A`로 상병/병장과 특기를 비교한다. rank는1~4, spec은A/B만 허용한다. 기존 debug URL에 새 항목이 없으면 기존 동작을 유지한다.
- `?scene=battle&unlock=all&supply=99&seed=7&deck=rifle:2`로 같은 이등병2장을 합쳐 실제 선택 모달을 확인한다. 다른 특기 합성과 대기석 포화 연쇄는 동일 debug 배치와 실제 보드/상점 동작으로 재현한다.
- 새 디버그 필드는 `src/debug.ts`에서 해석하고 덱 지급 옵션으로 전달한다. 게임 수치와 보상 로직은 바꾸지 않는다.

### 계획 검토에서 확정할 경계

- 다른 특기의 상병끼리 병장 합성도 같은 재선택 모달로 처리해 임의로 한 특기를 버리지 않는 방안.
- 화학병 A의 +1칸은 문구 그대로 제독 범위에 적용하고, 방독면 면역 범위는 GDD §5.6 기본 규칙과 구분하는 방안.
- 취사병 보급 효과의 다수 유닛 합산·정산1회성, 지뢰 기본 계급 토큰과 병장+2의 중복 계상 방지.
- 보직/특기별 규칙은 표로 두되 일반 효과 엔진·새 클래스·미래용 추상화를 만들지 않는다.
