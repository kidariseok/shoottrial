1. 기존 보병이 총을 들고도 1.5칸 근접 처리되는 구조 수정. 적별 사거리 적용, 첫 발은 짧은 조준 후, 후속은 정상 간격.
2. 돌격병(빠른 접근/연사)·방패병(직접 피해 감소/대전차 대응)·지정사수(긴 사거리/느린 조준) 추가.

4. 기존 애니메이션을 재사용하되 새3종은 틴트·병과표식·방패로 구분. 새 원본 그림 제작은 하지 않는다.
5. 초반 기본 교전→4웨이브 돌격→6웨이브 방패→7웨이브 지정사수→후반 혼합. 기존 적 수를 늘리기보다 보병 일부를 교체해 전체 규모를 유지.
6. 순수 계산 검증과 실제 전투에서 사격/아군HP감소/쓰러짐/치료 및 신규 조합 화면을 확인.
