# T-005 HUD·HP·게임오버·점수·재시작

상태: 대기
담당: Antigravity · gemini-4-argon-high

## 목표

전투에 한 판의 시작과 끝이 생긴다.
- HUD(세로 화면 위쪽, Safe Area 아래): 첫 줄 좌측 일시정지·HP 바·건빵, 둘째 줄 웨이브·점수. 우상단은 비운다.
- 피격 0.8초 무적(깜빡임), HP 30% 이하 붉은 비네팅
- HP 0 → "작전 실패" / 웨이브 3 클리어 → "작전 성공"(P2 임시. 보스는 P3)
- 결과 화면에서 점수·처치 수를 보고 [다시 출동]으로 즉시 재시작한다.

## 할 일

1. **`rules.ts`**: `score(run)`(GDD §4.7) + 테스트
   - 이번 티켓에서는 칼각 수 0, 무피격 웨이브까지만 계산한다.
2. **`player.ts`**
   - 피격 시 `hurtInvincible` 0.8초 + 알파 0.4↔1.0 깜빡임
   - 반경 40px 안의 잡졸을 살짝 밀어낸다.
3. **`hud.ts`**(Phaser, `setScrollFactor(0)`, `safeRect()` 안)
   - 첫 줄(왼쪽부터): [||] 일시정지(아직 동작은 `scene.pause()`와 재개 버튼만), HP 바, 건빵 수. 오른쪽 끝은 금지 구역이라 비운다.
   - 둘째 줄: `WAVE n/3`, 점수
   - 저체력 비네팅
   - **우상단 금지 구역 안에는 아무것도 그리지 않는다**(`?safe=1`로 확인).
4. **건빵 드롭**: 적 처치 시 `pickup_bread` 드롭. 웨이브가 끝나면 플레이어 쪽으로 빨려 들어와 합산된다.
5. **결과 오버레이**(Phaser 텍스트로 충분. DOM 화면은 P3)
   - "작전 성공"/"작전 실패", 점수, 처치 수, 획득 건빵, [다시 출동]
   - [다시 출동] → 씬 재시작. **재시작해도 이전 판의 객체·타이머·리스너가 남지 않아야 한다.**
