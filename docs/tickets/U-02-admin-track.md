## 할 일

1. 사업자등록. 이미 있으면 업종에 게임 소프트웨어 개발·공급을 추가할 수 있는지 확인한다.
2. **게임제작업 등록**(지자체, 게임산업법 §25). R-002가 정리한 서류와 절차를 따른다.
3. 등급분류 경로를 고르고 일정을 적는다.
   - 경로 A: 원스토어 '웹게임'으로 먼저 올려 자체등급을 받는다.
   - 경로 B: GRAC 직접 심의.
   - 어느 쪽이든 **플레이 가능한 빌드가 필요하다**. 실제 신청은 P3(G2)이 끝난 직후에 한다.
4. 앱인토스 콘솔 정산(광고 수익) 정보 등록에 필요한 것을 확인한다.
