# T-109 걸어 다니는 생활관(로비)

상태: 완료
담당: Antigravity · **Claude Sonnet 5.5 High** 또는 Gemini 최상위 모델(Argon 제외, 사고 수준 높음). 2번 막히면 다른 쪽으로 바꾼다.

## 목표

앱을 켜면 DOM 메뉴판 대신 **생활관 안을 직접 걸어 다니는 화면**이 뜬다(좀비고 대기실식, 사용자 확정 시안 "A-1").
- 조이스틱(키보드 방향키·WASD도 됨)으로 신병이 걷는다.
- 관물대·게시판·행정반·PX 앞에 서면 "열기" 말풍선이 뜨고, 누르면 해당 패널이 열린다.
- 출입구 앞에서 "전투 투입"을 누르면 전투가 시작된다. 오른쪽 아래에는 어디서나 누를 수 있는 "전투 투입" 버튼도 있다.
- 동료 두 명(이상병·박취사)이 서 있고, 다가가면 군 생활 풍의 한마디(전투 팁)를 한다.
- 군대 특성을 살린 게임이라는 점이 이 화면의 핵심이다. 사용자가 PX 상점 발상을 특히 좋아했다.

시안: https://claude.ai/artifact/8k9cK2wA5vW12taJjcQxU7 의 "A-1 생활관 내부 걷기"(`art/ref/ui-canvas/project/A-Walk1.dc.html`, 공개 저장소에는 없다. 필요하면 Claude에게 내보내 달라고 한다).

## 용어(사용자 확정 2026-10-24)

적이 쳐들어오는 상황이라 "출동"을 쓰지 않는다. 화면 문구는 모두 **"전투 투입"**으로 통일한다. 이 티켓이 다루는 로비 문구와 `lobby.ts`의 기존 "출동" 큰 버튼(`deployBtn`)도 바꾼다. `screens.ts`의 전투 중 버튼 "출동!"과 결과 화면 "다시 출동"은 T-110이 바꾼다(소유 파일이 겹치지 않게).

## 화면 규격

- **세계는 한 화면(720×1280)이다.** 스크롤하지 않는다. 배경 `bg_barracks`를 꽉 채운다(위에서 내려다본 생활관 내부).
- **배경 그림 구성(A-103과 같다)**
  - 위쪽 벽 왼쪽: 게시판
  - 위쪽 벽 오른쪽: 행정반(책상·문)
  - 왼쪽 벽: 관물대(사물함 줄)
  - 오른쪽 벽: PX 매대(과자·음료 선반)
  - 가운데: 2단 침상 두 줄과 가운데 통로
  - 아래 가운데: 출입구(붉은 불빛)
- **신병**: `ally_rifle_idle`(2프레임)을 쓴다. 걷는 동안만 2프레임을 번갈아 재생하고, 멈추면 1프레임. 왼쪽으로 가면 `flipX`. 방향별 걷기 그림은 없다.
- **동료 2명**: 이상병(`ally_sniper_idle`), 박취사(`ally_cook_idle`). 제자리에서 2프레임 재생.
- **구역(zone)** 5곳 + NPC 2명. 좌표는 `walk.ts` 맨 위의 표 하나(`ZONES`, `COLLIDERS`)에만 두고, 비율(0~1)로 적어 해상도가 바뀌어도 맞게 한다. 배경 그림이 오면 이 표만 다시 맞춘다.
- **충돌**: 침상·벽·가구는 직사각형 `COLLIDERS`로 막는다. 걷는 길이 침상 사이에 끼지 않게 축별로 따로 밀어낸다(대각선으로 벽에 비비며 미끄러지게).
- **Safe Area 안**에 UI를 둔다(`?safe=1`로 확인).

## 할 일

1. **`WalkScene`**(`walk.ts`): 위 규격대로 배경·신병·동료·구역·충돌.
   - 조이스틱: 화면 왼쪽 아래 어디든 누르면 그 자리에 스틱이 생기고(고정 위치 아님), 드래그한 방향·세기로 걷는다. 최대 속도는 상수 하나.
   - 키보드(개발용): 방향키·WASD.
   - 걷는 소리나 발소리는 넣지 않는다(T-106 소유 `audio.ts`는 고치지 않는다. 클릭음은 기존 `playSfx`만 쓴다).
2. **구역 상호작용**: 신병이 구역 반경 안에 들어오면 그 구역 위에 말풍선(이름 + 한 줄 설명 + "열기")이 뜨고, 벗어나면 사라진다. 가장 가까운 구역 하나만 뜬다. 오른쪽 아래 "열기" 원 버튼으로도 열 수 있다.
   - **관물대 → 병과 도감**: T-105의 도감 6칸을 패널로 띄운다.
   - **게시판 → 최고 기록 + "브리핑 다시 보기"**: 최고 웨이브(`save.bestWave`)와 브리핑 재생.
   - **행정반 → 설정·크레딧**: BGM·효과음·진동·데미지 숫자, 크레딧(허구 고지·AI 고지·오픈소스).
   - **PX → 광고 보급(자리만)**: 잠긴 카드 목록과 "광고 보고 해금" 비활성 버튼 + "준비 중". 실제 광고는 T-108이 이 자리에 연결한다. 연결 지점은 `openPx(onUnlock?: (card: string) => void)` 같은 함수 하나로 남기고 티켓에 이름을 적는다.
   - **출입구**: "위병소 방면 · 전투 투입" 말풍선. 오른쪽 아래의 큰 "전투 투입" 버튼은 어디서든 같은 동작.
3. **패널**: 기존 `lobby.ts`의 DOM을 "패널을 열고 닫는" 함수들로 쪼갠다. 패널이 열리면 신병은 멈추고 조이스틱 입력을 무시한다. 닫으면 다시 걷는다. 패널 안 문구와 동작은 T-105와 같다.
4. **동료 대사**(전투 팁). 다가가 반경 안에 들어오면 말풍선으로 한 줄씩, 누를 때마다 다음 줄로 돈다. 아래 문구를 그대로 쓴다(바꾸려면 `## 질문`).
   - 이상병(저격수): "저격은 관통이다. 한 줄로 세워 놓고 쏴라." / "사거리 안이면 어느 방향이든 쏜다. 대각선도 된다." / "적이 가까워지면 쏘기 전에 먼저 물러서라."
   - 박취사(취사병): "밥 먹고 해야지. 취사병이 옆에 있으면 다들 버틴다." / "제설병 뒤에 취사병을 세워라. 맞는 사람이 있어야 치료도 있지." / "짬밥 안 되는 소리 그만하고, 보급부터 챙겨라."
5. **흐름·씬 관리**(`main.ts`, `screens.ts`)
   - 첫 실행·브리핑은 그대로. 끝나면 `WalkScene`을 시작한다(DOM 메뉴판 생활관을 대체).
   - `lobby()`(A가 결과 화면에서 부른다)는 battle 씬을 멈추고 `WalkScene`을 시작한다. 시그니처 변화 없음.
   - "전투 투입"은 `game.scene.start('battle')`로 `WalkScene`을 멈추고 전투를 시작한다. 이전 판의 상태가 남지 않게 한다.
   - 기존 T-105의 `IdleScene`은 쓰지 않아도 되면 지운다. 지우는 이유를 진행 기록에 적는다.
   - 안드로이드 뒤로가기: 패널이 열려 있으면 패널을 닫고, 닫혀 있으면 기존 종료 확인 모달.
6. **상단 HUD**(DOM, 시안 A-1): 왼쪽 계급장 + 이름 + 계급 + 최고 웨이브, 오른쪽 설정(톱니) 버튼(행정반 설정 패널로 바로 열기). 훈장 같은 재화는 아직 없으니 넣지 않는다.
7. **디버그 URL**: `?scene=walk`(첫 실행·브리핑을 건너뛰고 걷는 화면을 바로 연다), `?zones=1`(구역 반경·충돌 사각형을 선으로 그린다). `docs/TECH.md` §9 표에 적을 문구를 결과 보고에 적는다(그 문서는 Claude가 고친다).
8. **비상 연출**(사용자 확정 2026-10-24): 생활관이 "비상 대기" 상태로 보이게 한다. 적이 쳐들어오는 중이라는 분위기를 걷는 내내 깔아 둔다.
   - **붉은 비상등**: 화면 전체에 붉은 덮개(`alpha` 0 ↔ 0.16)를 **2.4초 주기로 천천히** 맥동시킨다. 번쩍이지 않는다(초당 3회 이상 깜박임 금지, 광과민 배려). 위쪽 벽 양끝에 비상등 램프 2개(도형으로 그린 빨간 원 + 바닥으로 퍼지는 부채꼴 빛)를 두고 서로 반대 위상으로 켜진다. 신병·동료·가구 위에도 덮이도록 맨 위 레이어지만 입력은 막지 않는다.
   - **비상 방송 자막**: 화면 위쪽(Safe Area 안, HUD 아래)에 어두운 띠 + 붉은 왼쪽 선 + 글자 한 줄. 6초마다 다음 줄로 바뀌고 0.4초 페이드. 아래 문구를 그대로 쓴다.
     - "전 장병은 전투 투입하라. 위병소 방면 북방연합군 침투."
     - "비상 소집. 전 장병은 즉시 방어 위치로."
     - "현 시간부로 데프콘 2 발령. 위병소를 사수하라."
   - **소리**: 걷는 화면에 들어올 때 `playSfx('sfx_siren')`을 **한 번만**(반복하지 않는다), 방송 줄이 바뀔 때 `playSfx('sfx_radio')`. 파일이 없으면 조용히 건너뛴다. `audio.ts`는 고치지 않는다(T-106 소유, 기존 export만 쓴다). 설정에서 효과음을 끄면 나지 않는다.
   - **끄기**: 행정반 설정 패널에 "비상 연출" 토글(기본 켬)을 하나 더한다. 끄면 붉은 덮개·램프·방송 자막이 사라진다. 세이브 형식(`save.ts`)은 건드리지 않는다. 기기별 설정이므로 localStorage 키 `d2_alarm_fx`(`"0"`이면 끔, 없으면 켬)에 저장하고, 읽고 쓰는 헬퍼는 `helpers.ts`에 둔다.
   - 패널이 열려 있는 동안은 붉은 덮개를 절반으로 줄여 글자가 읽히게 한다. 방송 자막은 계속 돈다.
9. **테스트**(`tests/ui.test.ts`): 순수 헬퍼만.
   - `moveStep(pos, dir, speed, dt, colliders)`: 충돌에서 막힘, 벽에 비비며 미끄러짐, 정지.
   - `nearestZone(pos, zones)`: 반경 밖이면 null, 두 구역이 겹치면 가까운 쪽.
   - `stickVector(origin, point, maxRadius)`: 세기 0~1, 최대 반경에서 잘림.
   - `pulseAlpha(tMs, periodMs, max)`: 0~max 범위, 주기마다 반복, 주기가 1/3초보다 짧으면 안 된다(광과민 가드: 주기 인자가 333 미만이면 333으로 올림).
   - `nextLine(index, lines)`: 줄 순환.
