## 1. 한 줄 정의

**사이렌이 울리면 2분 안에 끝나는 출동.** 사방에서 몰려오는 폭주 도시 로봇들을 구르기와 두 자루 총으로 정리하는 세로형 탑다운 픽셀아트 슈터다. 출동할 때마다 계급이 오르고 전역이 다가온다.

| 항목 | 내용 |
|---|---|
| 플랫폼 | 토스 미니앱(앱인토스), **세로 화면**, 터치. 지하철에서 폰을 세워 든 채 할 수 있다 |
| 시점 | 위에서 비스듬히 내려다보는 탑다운(3/4 시점). 한 화면 아레나, 카메라 고정 |
| 세션 | 1판 약 2분, 로비 포함 1회 접속 5~10분 |
| 타깃 | ① 토스를 매일 쓰는 20~40대, 출퇴근·점심시간 2~5분 플레이 ② 메탈슬러그·탕탕특공대류를 좋아하는 아케이드 유저 |
| 등급 목표 | 전체 이용가 또는 12세(만화적 폭력, 비유혈, 기계 상대) |

### 1.1 이 게임만의 세 가지

1. **5분대기조라는 콘셉트**
   - 실제 군 용어(긴급 출동조)다. "사이렌 → 출동 → 복귀 보고"라는 짧은 단위가 미니앱 세션 길이와 정확히 맞는다.
   - 군 생활을 아는 사람(대부분의 한국 성인 남성, 드라마 〈D.P.〉·〈신병〉을 본 사람)은 설명 없이도 바로 이해한다.
2. **진짜 있을 법한 적**
   - 배달 로봇, 방범 드론, 청소 로봇은 이미 한국 거리에 있다.
   - 이것들이 폭주한다는 설정은 현실감과 웃음을 함께 주고, 기계라서 피 없는 연출도 자연스럽다.
3. **판마다 다른 빌드 + 긴 목표**
   - 판 안에서는 보급 카드 2장을 골라 빌드를 만든다.
   - 판 밖에서는 계급과 복무일수(전역까지 D-day)가 쌓인다.

## 2. 세계관

### 2.1 배경

- 2031년, 수도권 스마트시티 방위 AI **'GRAY'**가 정체불명의 해킹을 당한다.
- GRAY가 관리하던 배달·방범·청소·물류 로봇이 일제히 사람을 '오염물'로 인식하고 폭주한다.
- 경찰 로봇은 이미 GRAY 편이다. 남은 것은 사람이 직접 지키는 부대뿐이다.

### 2.2 우리 편

| 육군 **제77기동타격대 '불곰'** | 플레이어 소속(가상 부대) | 부대 마크는 곰 발바닥 + 번개(가상) |

## 3. 조작

세로 화면. **엄지 하나로도 할 수 있게** 만든다. 두 엄지를 쓰면 더 편하다.

| 입력 | 위치 | 동작 |
|---|---|---|
| **이동** | 화면 아래쪽 60% 어디든(버튼 영역 제외) | 터치한 곳에 조이스틱이 생긴다(플로팅). 360도, 아날로그 세기 |
| **사격** | 없음(자동) | 사거리 안에 적이 있으면 가장 가까운 적을 자동으로 조준해 쏜다 |
| **구르기 ①** | 오른쪽 아래 큰 버튼 | 이동 방향으로 구른다. 0.25초 무적, 쿨타임 원형 게이지 |
| **구르기 ②(한 손)** | 조이스틱을 쥔 엄지를 한 방향으로 빠르게 튕기기 | 튕긴 방향으로 구른다. 설정에서 끌 수 있고 기본은 켬. 판정 수치는 `PAD.flick` |
| **특수화기** | 구르기 버튼 위 작은 버튼 | 누르면 특수화기로 바꿔 자동 사격한다. 과열되거나 다시 누르면 소총으로 돌아온다. 열기 게이지 표시 |
| 일시정지 | 왼쪽 위 | 일시정지 모달 |

**캐릭터 방향**
- 몸은 조준 중인 적 쪽(없으면 이동 방향)을 본다. 몸 방향은 아래·위·옆 3가지이고, 옆은 좌우 반전으로 처리한다.
- 총은 조준 방향으로 360도 회전한다.

**원안과 다른 점**
- 사격 버튼을 없애고 자동 사격으로 바꿨다.
- 이유
  - 토스 유저는 캐주얼하다. 사격 버튼을 계속 누르고 있으면 엄지가 묶여 구르기 타이밍을 놓친다.
  - 입력이 줄면 멀티터치 버그도 줄고, 세로 화면에서는 한 손 플레이가 된다.
- 대신 실력이 드러나는 지점: **위치 선정, 구르기 타이밍(칼각 회피), 특수화기를 언제 터뜨릴지.**

## 4. 전투 규칙

좌표는 내부 해상도 **360×640**(세로) 기준이다(`docs/TECH.md` §3).

### 4.1 플레이어

| 항목 | 초기값 | 메모 |
|---|---|---|
| 최대 HP | 100 | 방탄복 강화 +10%/Lv |
| 이동 속도 | 110 px/s | |
| 아레나(이동 가능 영역) | x 12~348, y 60~612 | 가장자리 장식 안쪽. 시작 위치 (180, 420) |
| 히트박스 | 10×10 px(발 쪽 몸통) | 스프라이트(약 28px)보다 작게 해서 억울한 피격을 줄인다 |
| 구르기 | 0.25초, 속도 ×3.2(약 88px), 쿨 2.0초 | 무적 |
| 한 손 구르기(튕기기) | 120ms 안에 조이스틱 중심에서 40px 이상 이동 | `PAD.flick`. 오작동이 많으면 G1에서 조정 |
| **칼각 회피** | 구르기 시작 후 0.15초 안에 적 공격 판정이 겹치면 성공 | "칼각!" 팝업, 특수화기 열기 -50%, +150점. 내부 쿨 1초 |
| 피격 무적 | 0.8초 | 반투명 깜빡임. 주변 40px 잡졸을 살짝 밀어낸다 |
| 저체력 경고 | HP 30% 이하 | 화면 가장자리 붉은 비네팅 |

### 4.2 무기

| ID | 이름 | 슬롯 | 연사 간격 | 피해 | 탄속 | 사거리 | 열기 | 특징 |
|---|---|---|---|---|---|---|---|---|
| `rifle` | 제식소총 | 주 | 160ms | 10 | 400 px/s | 200 | 없음 | 기본 무기, 무한 |
| `grenade` | 유탄발사기 | 특수 | 480ms | 30(반경 40) | 260 px/s | 220 | +18%/발 | 조준한 적 위치에 착탄, 넉백 강, 방패 무시 |
| `jammer` | 드론 재밍건 | 특수 | 400ms(파동) | 6 | — | 120, 70° 부채꼴 | +15%/파동 | 드론을 1.5초 추락·정지시킨다(받는 피해 ×2). 일병 진급 시 해금 |

**자동 조준**
- 사거리 안에서 가장 가까운 적을 노린다.
- 한 번 잡은 적은 죽거나 사거리 +20을 벗어날 때까지 유지한다(조준 떨림 방지).
- 사거리 안에 적이 없으면 사격하지 않는다(탄 낭비·소음 방지).

**열기**
- 100%가 되면 **과열**: 3초 동안 특수화기를 쓸 수 없고 자동으로 소총으로 돌아온다.
- 특수화기를 쓰지 않는 동안 초당 25%씩 식는다.

**특수화기 장착**
- 판에 들고 가는 특수화기는 1개다.
- 로비에서 유탄발사기와 재밍건 중에 고른다.

**스테이지 보정**
- 잡졸 HP·공격 ×(1 + 0.25×(스테이지−1))
- 무한 비상: 웨이브마다 ×1.12 복리, 4웨이브마다 보스가 돌아가며 나온다.

**등장과 분리**
- 적은 아레나 밖 네 변(위 `T`·왼쪽 `L`·오른쪽 `R`·아래 `B`)에서 들어온다.
- 아래쪽은 엄지가 가리는 곳이라 전체 등장의 20% 이하로 한다.
- 지상 적끼리는 반경 12px 안에서 서로 밀어내 겹치지 않게 한다.
- 화면 밖에서 등장한 적은 아레나 안에 들어올 때까지 경계 충돌을 끈다.

### 4.4 웨이브 구성 (스테이지 1 예시, 나머지는 `src/stages.ts`)

| 보스 | ~35초 | 철책이 | 예고 보고 구르기 |

**웨이브 종료 조건**
- 그 웨이브의 적을 모두 처치하면 끝난다.
- 웨이브 시작 후 40초가 지나면 화면 밖 적을 화면 안으로 끌어들인다(진행 막힘 방지).

**동시 활성 상한**: 적 25, 적 탄 40, 아군 탄 60, 파티클 80

### 4.5 보급 카드 (판 안의 선택)

- 웨이브 1·2가 끝나면 3장을 보여주고 1장을 고른다. 판마다 한 번 고른 카드는 다시 나오지 않는다.
- 카드를 고르는 동안 게임은 멈춘다. 고르는 데 시간 제한은 없다.
- 카드는 빨리 읽혀야 한다. 이름은 짧은 군대 말투로, 효과는 숫자로 표기한다.

| ID | 이름 | 효과 |
|---|---|---|
| `ammo` | 탄약 추가 지급 | 소총 연사 +15% |
| `senior` | 선임의 조언 | 구르기 쿨 −20% |
| `plate` | 방탄판 보강 | 최대 HP +25%(그만큼 회복) |

| `bigboom` | 유탄 개조 | 유탄 반경 +30% |
| `coolpad` | 냉각 패드 | 열기 냉각 +40% |
| `pierce` | 관통탄 | 소총 탄이 적 1기를 관통 |

### 4.6 사망·부활

- HP 0 → 판당 1회, **광고가 로드되어 있을 때만** "지원 사격 요청" 모달을 띄운다(5초 카운트다운).
  - 시청을 완료하면 HP 100% + 3초 무적 + 포병 지원 사격 연출(화면 내 적 전체 넉백 + 피해 50)로 즉시 재개한다.
  - 거절, 시간 초과, 광고 없음 → 바로 복귀 보고(정산)로 간다.
- 두 번째 사망은 바로 정산이다.
- 보스 HP가 0이 되면 화면의 적 탄과 잡졸을 모두 없앤다. 보스와 동시에 죽는 일을 막기 위해서다. 연출은 0.4초 슬로모션 + 보스가 김을 뿜으며 주저앉기.

### 4.7 점수 (리더보드 제출)

```
점수 = 처치 점수 합 + 칼각 회피 수×150 + 클리어 보너스(스테이지×2000) + 남은 HP%×10 + 무피격 웨이브 수×500
```

- 판이 끝날 때마다 최고 점수를 제출한다. 무한 비상에서는 도달 웨이브가 점수를 크게 끌어올린다.

### 5.1 계급과 복무일수

- 육군 18개월(547일)을 그대로 쓴다. 로비 상단에 **"전역까지 D-○○○"**를 표시한다.

|---|---|---|
| 이병 | 0 | — |
| 일병 | 61 | **드론 재밍건 해금** |
| 상병 | 243 | 특수화기 슬롯 강화(열기 최대치 +20%) |
| 병장 | 425 | 칭호 "말년", 건빵 +10% |
| **전역** | 547 | 전역증 연출 + 훈장 1개(영구 건빵 +10%, 최대 5개) → **예비군 N년차**로 복무일수가 0부터 다시 쌓인다. 강화 수준은 유지 |

출동 1회의 복무일수
```
3 + 클리어한 웨이브 수×2 + 보스 처치 8 + (스테이지−1)×3
```
- 스테이지 1 클리어 시 약 17일 → 일병까지 약 4판, 전역까지 약 30판(하루 5판 기준 약 1주)
- **일일 점호**: 그날 첫 출동은 복무일수·건빵 ×2. 마지막 출동 날짜를 저장해 비교한다.

### 5.2 PX (영구 강화, 재화: 건빵)

| ID | 이름 | 효과/Lv | 최대 |
|---|---|---|---|
| `atk` | 총기 손질 | 소총 피해 +12% | Lv 20 |
| `heavy` | 특수화기 정비 | 특수화기 피해 +15%, 냉각 +5% | Lv 20 |
| `armor` | 방탄복 교체 | 최대 HP +10% | Lv 20 |

```
비용(Lv n → n+1) = round(100 × 1.22^(n−1))
```
- Lv1→2: 100, Lv5→6: 221, Lv10→11: 598, Lv19→20: 3,576

판당 건빵 기대값 (튜닝 기준)

| 스테이지 1 | 스테이지 2 | 스테이지 3 | 무한 비상 |
|---|---|---|---|
| 약 150 | 약 260 | 약 400 | 웨이브×40 |

- 실패해도 그때까지 모은 건빵은 100% 받는다.
- 첫 판이 끝나면 무조건 강화를 1회 할 수 있게 한다(100 이상).

## 6. 한 번 접속의 흐름

```
[토스에서 실행] → 타이틀(3초 안에, 첫 터치로 오디오 해제)
   → 생활관(로비) ── PX 강화 / 특수화기 선택 / 스테이지 선택 / 랭킹 / 설정
   → [출동!] 사이렌 + 김 하사 무전 1줄
   → 웨이브1 → 카드 → 웨이브2 → 카드 → 웨이브3 → 보스 경보 → 보스전
   → (사망 시) 지원 사격 요청(광고, 선택)
   → 복귀 보고(정산): 건빵·복무일수·점수, [광고 보고 포상 2배] / [받기] / [바로 재출동]
   → (진급했다면) 진급 연출
   → 생활관
```

### 6.1 첫 판 (튜토리얼 없이 배우게)

- 첫 실행이면 웨이브 1 시작 3초 동안 반투명 손가락 화살표를 띄운다. "드래그해서 이동", "위험하면 구르기(무적)!"
- 게임을 멈추지 않고 띄웠다가 사라지게 한다.
- 스테이지 1 웨이브 1은 배달 로봇만 나온다. 첫 적은 1.5초 안에 등장한다.

### 6.2 무전 대사 (톤 샘플, 전체는 C 티켓에서 작성)

| 상황 | 화자 | 대사 |
|---|---|---|
| 첫 출동 | 김 하사 | "신병, 실전이다. 저건 그냥 택배 상자가 아니야. 쏴!" |
| 배달 로봇 첫 등장 | 박 병장 | "치킨 들었으면 살살 쏴라. ...농담이다. 다 쏴." |
| 방범 드론 첫 등장 | 김 하사 | "빨간 선이 보이면 비켜. 그 선이 탄 지나갈 길이다." |
| 보스 경보 | 김 하사 | "대형 기체 접근! 바닥 빨간 띠 보이면 무조건 구른다!" |
| 칼각 회피 10회 | 박 병장 | "칼각 나오네. 너 전역하면 나 대신 분대장 해라." |
| 사망 | 김 하사 | "불곰 1, 응답하라! ...지원 사격 요청할까?" |
| 진급(일병) | 박 병장 | "일병 축하한다. 이제 재밍건 줄 테니까 드론은 네가 잡아." |

**대사 원칙**
- 한 줄 30자 이내로 쓴다.

- 하나의 직업이나 성별을 놀리지 않는다.

| 보스 등장 | 사이렌 + 흔들림(중) + 경보 띠 | 경보음 | 중 1회 |
| 보스 처치 | 0.4초 슬로모션 + 대폭발 + 건빵 쏟아짐 | 팡파르 | 성공 패턴 |
| 진급 | 계급장 교체 + 경례 + 빛줄기 | 나팔 | 성공 패턴 |

- 진동은 0.08초 이상 간격을 두어 브릿지 과호출을 막는다.
- 화면 흔들림은 겹쳐도 상한을 둔다.
- 설정에서 진동과 흔들림을 끌 수 있다.

## 9. 수익화 (보상형 광고만)

| 지점 | 언제 | 효과 | 횟수 |
|---|---|---|---|
| 지원 사격 요청 | 사망 시 | HP 100% + 3초 무적 + 화면 넉백 | 판당 1회 |
| 포상 2배 | 정산 화면 | 이번 판 건빵 2배 | 판당 1회 |

- 전면 광고와 배너는 MVP에 넣지 않는다.
- **광고를 한 번도 안 봐도** 모든 콘텐츠를 깰 수 있게 밸런스를 잡는다.
- 광고 그룹은 1개로 두 지점이 같이 쓴다. 어느 지점인지는 분석 이벤트로 구분한다.

## 10. 측정 (분석 이벤트 최소 세트)

| 이벤트 | 파라미터 | 보는 지표 |

## 12. 원안 대비 변경 요약

| 원안 | 변경 | 이유 |

| 한국군 vs 북한군 모티브 | 5분대기조 vs 해킹 로봇 | 오픈 정책의 '사회적 논란' 조항 반려 위험 제거, 비유혈이 자연스러워짐 |

| 광고 그룹 2개 순차 로드 | 그룹 1개 공용 | 순차 로드 큐 자체가 필요 없어짐 |
