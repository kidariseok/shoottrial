# 아이폰 미러링 플레이 점검 인계

상태: 미러링 제어 연결 차단 / 고밀도 전투 성능 판정 미완료
최종 갱신: 2026-10-31, Codex

## 요청과 범위

사용자는 실제 아이폰 미러링 창에서 게임을 진행하며 웨이브/캐릭터가 많아질 때의 멈춤·입력 지연·표시 이상을 기록해 작업자에게 넘기도록 요청했다. 게임 코드·배포·기기 설정은 변경하지 않았다. 이 문서는 실행한 관찰과 아직 하지 못한 측정을 구분한다.

## 환경/버전

- 관찰 도구: macOS iPhone 미러링 앱(com.apple.ScreenContinuity), CUA 앱 화면 캡처/입력.
- 2026-10-31 연결 안내에서 기종 iPhone15Pro 확인. iOS버전/발열/메모리/프레임 계측값은 확인하지 않음.
- 화면: Safari 하단 주소가 …defense.vercel.app으로 보이는 모바일 웹 체험판. 주소 전체/캐시된 번들 커밋은 아이폰에서 확인하지 못했다.
- PR52: 2026-10-30T13:27:52Z 병합, merge commit3e54c66e521d045ab8a0b3d7cbfe8fbbd3bc772b. GitHub CLI 실제 조회 결과다. 병합 사실만으로 아이폰 캐시가 그 배포를 사용했다고 단정하지 않는다.
- PR52 이전 관찰과 병합 이후 관찰을 직접적인 개선 전후 벤치마크로 비교하지 않는다.

## 재시험(2026-10-31)

사용자의 ‘다시 테스트해봐’ 요청에 앱 상태를 새로 확인했다. 처음 ‘iPhone15Pro에 연결 중’이 표시됐고, 다음 관찰에서 ‘iPhone 잠금 해제’ 안내와 연결 버튼이 표시됐다. 게임 화면은 아직 열지 못했다. 사용자에게 기기에서 잠금 해제 안내를 완료한 뒤 재연결하도록 요청했다. 비밀번호/인증코드는 수집하지 않는다.

## 작업자가 먼저 확인할 항목

1. **관찰 경로 검증:** 사용자 화면/실제 폰에서는 전장과 유닛이 보이는데 CUA 캡처만 검은지 먼저 대조한다. 이 확인 전에 WebGL버그라고 결론 내리거나 렌더러를 교체하지 않는다.
2. **배포 식별:** 폰에 로드된 빌드/커밋과 PR52 포함 여부를 확인한다. 캐시 갱신 여부도 기록한다.
3. **전장 자체가 검은 경우:** 생활관→전투 전환에서 canvas 크기/visibility와 WebGL context lost/restored 및 리소스 오류를 수집한다. DOM HUD가 정상이어도 canvas 표시 경로는 별도로 확인해야 한다. 이것들은 진단 후보이며 관찰로 확정된 원인은 아니다.
4. **고밀도 전투 성능:** 전장이 정상 표시되는 상태에서 같은 seed/배치/배속/이펙트 설정으로5·7·9·10웨이브를 비교한다. 아군 수·생존 적 수·화면효과·입력 시점·복구 여부를 함께 기록한다.
5. **측정값:** requestAnimationFrame 프레임 시간(p50/p95/p99/최대), 긴 프레임 횟수, 유닛 수, 파티클/텍스트/트윈 수를 함께 수집한다. 이번 미러링 캡처만으로 평균/최저FPS를 추정하지 않는다.

## 하지 않은 검사/증거 제한

- 웨이브10까지 agent가 직접 정상 플레이했다거나, 고밀도에서 FPS가 떨어졌다고 주장하지 않는다.
- 이번 세션의 데이터로 인과관계/성능 개선 통과를 판정하지 않는다.
- CUA 캡처 이미지는 대화 안에서 관찰했다. 별도 스크린샷 파일이나 연속 녹화 파일은 아직 만들지 않았으므로 파일 경로를 증거로 적지 않는다.
- npm run verify는 게임 코드 변경 없는 실기기 관찰 작업이므로 실행하지 않았다. 이전 음악/효과음 작업의396테스트 결과는 이 실기기 성능 측정 결과가 아니다.
- 사용자 개인 앱/알림/계정명은 수집·보고하지 않는다. 기기 잠금 해제는 사용자가 수행한다.

## 추가 재시험: 사용자 재연결 후

- 사용자 재연결 완료 후 미러링에서 Safari 주소 입력 화면까지 확인했다.
- 체험판 주소를 넣는 중 제어 도구가 붙여넣기 충돌 오류를 반환했고, 다음 관찰에서 미러링 앱이 ‘연결이 중단됨’을 표시했다. 입력된 주소가 제출됐다고 주장하지 않는다.
- 앱의 ‘다시 시도’를 실제 클릭한 뒤 iPhone15Pro 연결 중 화면으로 전환되는 것까지 확인했다. 이는 게임 실행 중 크래시가 아니라 게임 진입 전 미러링 연결 문제로 분류한다.
- 이 추가 시도에서는 전투/고밀도 장면을 아직 실행하지 못했다.

- 추가 재접속 결과: 첫 재시도는 앱의 ‘iPhone 미러링 연결 시간이 초과되었습니다’로 종료됐다. 앱의 연결 버튼으로 두 번째 재접속을 시작했다. 이 과정에서 Wi-Fi/Bluetooth/보안 설정은 변경하지 않았다.

- 두 번째 재접속의 실제 안내: ‘iPhone 사용 중 — 연결하려면 iPhone을 잠그십시오. iPhone이 더 이상 사용되지 않을 때 iPhone 미러링이 연결됩니다.’ 사용자에게 폰 화면을 잠그고 테스트 중 직접 사용하지 않도록 요청했다. 현재의 직접적인 차단 원인은 폰 사용 중 상태다.

## 이번 요청의 종료 상태

사용자에게 폰 잠금 상태 유지를 요청하고20초 대기 후 앱 상태를 조회했지만 `Computer Use server error -10005: cgWindowNotFound`가 발생했다. 앱을 bundle ID로 다시 선택하는 다른 복구 시도도 같은 오류로 끝났다. 창을 실제로 닫았는지/전송 서버가 창을 잃었는지는 확인하지 못했다. 세 번째 같은 복구 시도는 하지 않았다.

따라서 이번 재시험에서는 게임에 진입하지 못했다. 게임 코드/CPU/GPU 문제나 고밀도 전투 렉의 증거로 이 연결 오류를 사용하면 안 된다. 지금 넘길 수 있는 것은 위 연결·관찰 기록과 다음 측정 항목이며, 실제 성능 합격/실패 판정은 없다.
