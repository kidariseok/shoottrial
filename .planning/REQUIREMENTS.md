# Requirements: 데프콘 2: 화스트 페이스 (가제)

**Defined:** 2026-10-20
**Core Value:** 배치 조합이 결과를 바꾸고, 끝나면 "한 판 더"를 누르고 싶은 10웨이브 한 판(도형만으로).
**Scope:** 레인 A(Claude Code)의 M2 그레이박스 코어. 근거는 `docs/GDD.md` §3~§8, §11과 `docs/TECH.md` §2, §3, §8, §9다. 숫자는 모두 GDD의 실험 가설이고 코드에서는 `src/data.ts`·`src/stages.ts`에만 둔다.

## v1 Requirements (M2, 레인 A)

### 판·배치 (BOARD)

- [ ] **BOARD-01**: `?scene=battle`에서 판이 도형으로 그려진다. 720×1280 기준 y 구역은 HUD 0~96(비워 둔다), 적 진입 2행 96~352, 지뢰 구역 5×2 352~608, 배치 구역 5열×3행 608~992, 위병소 방어선 992, 대기석 5칸 1040~1160이다. 5열, 칸 128, 좌우 여백 40. 좌표는 모두 `data.ts`의 `LAYOUT` 상수 하나에서 온다(`SPRITE_SCALE`도 `data.ts`). (GDD §3, TECH §3)
- [ ] **BOARD-02**: 카드를 대기석과 배치 구역 사이로 끌어 옮길 수 있다. 끄는 동안 놓을 수 있는 칸이 강조된다. 놓을 수 없는 곳에 놓으면 가장 가까운 빈 칸으로 보정되고, 빈 칸이 없으면 원위치로 돌아간다. (GDD §8)
- [ ] **BOARD-03**: 같은 카드·같은 계급 2장을 대기석이나 배치 구역에서 겹치면 다음 계급 1장이 된다(이등병 → 일병 → 상병 → 병장). 합성할 수 있는 카드 위로 끌면 계급 표시가 반짝이고, 합성되면 계급 표시 확대 + "진급!" 팝업(도형)이 뜬다. 카드 도형에 보직과 계급이 보인다. (GDD §5.3, §8, §9)
- [ ] **BOARD-04**: 카드를 팔면 들인 비용 전액이 보급으로 돌아온다. 합성된 카드는 재료 비용의 합이다. (GDD §6)
- [ ] **BOARD-05**: 매 판 시작 때 신병 소총수 1장(이등병, 이름 = 저장된 신병 이름, 없으면 "김신병")이 배치 구역 가운데 열 맨 아래 칸에 놓이고 보급은 6이다. 이 카드는 다른 소총수처럼 합성·판매되며, 합성 결과가 이름을 물려받는다. (GDD §2.1, §5.2)

### 순수 규칙 (RULE) — `src/rules.ts` + `tests/rules*.test.ts`, 테스트 먼저

- [ ] **RULE-01**: `data.ts`에 카드 5종(소총수·저격수·제설병·취사병·지뢰설치병)의 이등병 수치, 계급 배율 ×1.5, 계급별 필요 장수(일병 2, 상병 4, 병장 8), 시너지 표, 경제 수치가 GDD §5.2~§5.4, §6과 1:1로 있다.
- [ ] **RULE-02**: 합성 함수가 같은 카드·같은 계급일 때만 다음 계급을 돌려준다. 계급별 HP·공격이 ×1.5씩 오르고, 병장은 더 오르지 않는다. 테스트로 증명한다.
- [ ] **RULE-03**: 시너지 집계 함수가 **배치 구역 인원 수**(계급 무관)로 보직별 2명/4명 단계를 계산하고 `Hud.synergies` 모양(`{card, count, on}[]`)을 돌려준다. 합치면 인원이 줄어 시너지가 꺼지는 경우를 테스트한다. (GDD §1.1, §5.4)
- [ ] **RULE-04**: 이자·정산 수입 함수: 보유 보급 5당 +1(최대 +2), 기본 수입 5, 깃발 웨이브 +3, 조기 출동 +1. 테스트로 증명한다. (GDD §6)
- [ ] **RULE-05**: 웨이브 스케일 함수: 적 HP ×(1 + 0.12 × (웨이브 − 1)). 테스트로 증명한다. (GDD §5.6)
- [ ] **RULE-06**: 상점 추첨 함수: 해금된 카드 중 균등 확률로 5칸을 뽑는다. 같은 시드면 같은 결과다(H-101의 `rand()` 또는 주입한 난수). 테스트로 증명한다. (GDD §6)
- [ ] **RULE-07**: 판매 환급 함수: 이등병 비용 × 재료 장수(1·2·4·8). 테스트로 증명한다. (GDD §6)

### 전투 루프 (LOOP)

- [ ] **LOOP-01**: `BattleScene`의 `phase` 변수 하나(`'prep' | 'fight' | 'settle'`) + `switch`로 준비 → 전투 → 정산을 10웨이브 반복한다. 준비는 웨이브 1에서 30초, 이후 20초이고 시간이 끝나면 전투가 시작된다. 정산은 1.5초다. 웨이브 10을 클리어하면 승리로 판이 끝난다. (GDD §4, TECH §2.1)
- [ ] **LOOP-02**: 전투 중에는 대기석 카드를 빈 칸에 투입하는 것(합성 포함)만 된다. 배치된 카드 이동·판매와 지뢰 매설은 막힌다. (GDD §4)
- [ ] **LOOP-03**: 전투가 끝나면 아군 HP가 모두 회복되고 쓰러진 아군이 제자리에서 다시 일어난다. 판 안에서 영구히 잃는 것은 위병소 HP와 최후 저지선뿐이다. (GDD §4)
- [ ] **LOOP-04**: 웨이브 7~10은 데프콘 1이다. 아군 공격 간격 ×0.8, 적 출현 간격 ×0.7이 적용된다(규칙만, 연출은 M3). (GDD §4.1)
- [ ] **LOOP-05**: 2배속(1 | 2)으로 전투·준비 타이머·트윈이 모두 두 배로 진행된다. `?speed=2`로 2배속으로 시작한다. (GDD §4, TECH §9)

### 차선 판정 (LANE)

- [ ] **LANE-01**: 판정은 열 단위 1D다. 아군은 자기 열에서 사거리(칸) 안의 가장 가까운(가장 아래) 적을 노린다. 적은 위에서 아래로 걷다가 같은 열의 가장 앞(가장 위) 아군을 만나면 멈춰 공격한다. 투사체는 같은 열에서만 맞는다. 2D 충돌·길찾기는 없다. (GDD §5.1, TECH §2.1)

### 카드 메커니즘 (CARD)

- [ ] **CARD-01**: 소총수는 사거리 4칸 안의 적에게 단발 사격한다.
- [ ] **CARD-02**: 저격수는 같은 열의 적을 모두 관통하고, 뒤의 적일수록 피해가 −20%씩 줄어든다. 한 열로 몰려오는 종대를 끊을 수 있다.
- [ ] **CARD-03**: 제설병은 사거리 2칸 안 같은 열의 적을 모두 1칸 위로 밀어내고 밀린 적의 공격 준비를 취소한다(히트백). 군견은 ×1.5, 보스는 ×0.25만큼 밀린다.
- [ ] **CARD-04**: 취사병은 인접 8칸의 아군을 12씩 회복하고, 웨이브가 시작될 때 인접 아군의 최대 HP를 +20%("짬밥") 올린다.
- [ ] **CARD-05**: 지뢰설치병은 사거리 3칸 안의 적을 공격하고(6 / 1.0초) 준비 단계마다 지뢰 토큰을 받는다(MINE-01).
- [ ] **CARD-06**: 상병·병장 능력이 열리고 누적된다. 소총수 2점사 / 말년(간격 −20%). 저격수 관통 피해 감소 없음 / 첫 명중 대상 1초 기절. 제설병 화염 송풍(밀린 적에게 3초간 초당 8) / 밀어내기 2칸. 취사병 웨이브마다 쓰러진 인접 아군 1명을 HP 50%로 일으킴 / 회복 범위 2칸. 지뢰설치병 대전차 지뢰(보스 피해 ×3) / 토큰 +2. (GDD §5.3)
- [ ] **CARD-07**: 배치 구역 인원 수로 켜진 시너지가 전투에 적용된다. 소총수 2/4명: 공격 간격 −20%/−40%. 저격수 2명: 피해 +30%. 제설병 2/4명: 밀어내기 +50%/사거리 3칸. 취사병 2명: 회복 대상이 배치 구역 전원. 지뢰설치병 2명: 토큰 +1. (GDD §5.4)

### 지뢰 (MINE)

- [ ] **MINE-01**: 준비 단계가 시작될 때 지뢰설치병의 수·계급(이등병 1, 일병 2, 상병 3, 병장 4 + 병장 능력 +2)과 시너지(+1)에 맞는 지뢰 토큰이 대기석 옆에 생긴다. 토큰을 지뢰 구역(5×2)으로 끌어 한 칸에 1개씩 묻는다. 묻은 지뢰는 반투명으로 보인다. 쓰지 않은 토큰은 전투가 시작되면 사라진다. (GDD §5.5)
- [ ] **MINE-02**: 적이 지뢰 칸에 들어오면 터져 그 칸과 위아래 1칸의 적 모두에게 150 피해를 준다(대전차 지뢰는 보스에게 ×3). 묻은 지뢰는 터질 때까지 웨이브를 넘겨 남는다. (GDD §5.5)

### 적 (ENEMY)

- [ ] **ENEMY-01**: 보병(HP 60, 0.35칸/초, 아군에게 10/1초, 위병소 피해 1)이 걷다가 막히면 공격한다.
- [ ] **ENEMY-02**: 군견(HP 40, 0.9칸/초, 6/0.5초, 위병소 1)은 배치 구역에 들어설 때 아군이 가장 적은 옆 열로 한 번 옮긴다(옆으로 이동하는 트윈 1회).
- [ ] **ENEMY-03**: RPG병(HP 50, 0.3칸/초, 위병소 2)은 같은 열 3칸 안에 아군이 들어오면 멈춰서 그 칸에 35 범위 피해를 3초마다 준다.
- [ ] **ENEMY-04**: 보스 장갑차(HP 1200, 0.15칸/초, 막은 아군에게 40/1초, 위병소 5)는 등장할 때 같은 열 아군을 1.5초 기절시킨다(충격파). 밀어내기는 ×0.25만 받는다.

### 웨이브 (WAVE)

- [ ] **WAVE-01**: `stages.ts`에 스테이지 1 웨이브 1~10 구성이 GDD §5.7과 1:1로 있다(깃발 웨이브 5·10, 종대 = 보병 5가 한 열에 0.5초 간격). 출현 간격은 기본 1.2초이고 열은 시드 난수로 고른다. 적 HP에는 RULE-05 스케일이 적용된다.

### 위병소 (BASE)

- [ ] **BASE-01**: 위병소 HP는 20이다. 적이 방어선에 닿으면 적마다 정해진 피해(보병·군견 1, RPG 2, 보스 5)만큼 HP가 깎인다. HP가 0이 되면 판이 패배로 끝난다(부활 제안 연결은 UI-01). (GDD §4.2)
- [ ] **BASE-02**: 열마다 최후 저지선이 1회 있다. 그 열에서 처음으로 적이 방어선에 닿으면 저지선이 발동해 그 열의 적을 모두 쓸어내고 HP는 깎이지 않는다. 다 쓴 열은 판 위에 표시된다. (GDD §4.2)

### 손맛 (FX) — 도형

- [ ] **FX-01**: 아군 사격 섬광·탄 궤적, 저격 흰 선 + 짧은 흔들림, 송풍 파동 + 적이 위로 미끄러짐, 지뢰 폭발 + 흔들림, 최후 저지선 열 섬광 + 흔들림, 피격 흰 번쩍 + 데미지 숫자, 쓰러짐 + 페이드(피 없음)가 도형으로 보인다. (GDD §9)

### 디버그 (DBG)

- [ ] **DBG-01**: `?deck=rifle:4,sniper:2`로 대기석에 카드가 지급되고 `?supply=99`로 시작 보급이 정해진다(H-101의 `debug` 값을 읽는다). (TECH §9)
- [ ] **DBG-02**: `?wave=5`로 지정 웨이브부터 시작하고, `?god=1`이면 위병소가 깎이지 않으며, `?seed=42`면 같은 출현 순서·열이 매번 재현된다. (TECH §9)

### 경제 (ECON)

- [ ] **ECON-01**: 정산 때 기본 수입 5 + 이자 + 깃발 웨이브 보너스 +3이 보급에 더해진다. 준비 시간이 끝나기 전에 "출동!"(`onGo`)을 누르면 바로 전투가 시작되고 보급 +1을 받는다. (GDD §4, §6)
- [ ] **ECON-02**: 준비 단계가 시작될 때마다 상점 5칸이 무료로 새로 채워진다. 리롤은 보급 1이다. 구매(`onBuy(i)`)하면 보급이 차감되고 카드가 대기석에 들어간다. 대기석이 가득 차도 사는 순간 합성되면 허용한다. 전투·정산 중에는 상점이 닫힌다. (GDD §5.3, §6)

### 화면 연결 (UI) — `ui/screens.ts` 호출만, DOM은 레인 B

- [ ] **UI-01**: `BattleScene`이 TECH §8 함수를 부른다. `hud()`는 값이 바뀔 때만, `shop()`은 준비 단계 열림·닫힘 때, `banner()`는 깃발 웨이브("대규모 적 접근!")·데프콘 전환·안내 때, `cardInfo()`는 카드를 길게 눌렀을 때, `askRevive()`는 HP 0일 때, `result()`는 판이 끝날 때(도달 웨이브·처치 수·새 해금). T-102 전에는 H-101의 빈 함수로도 판이 멈추지 않고 진행된다.
- [ ] **UI-02**: 전투 시작 때 `bindBattle(ctl)`, 끝날 때 `bindBattle(null)`을 부른다. `ctl.pause()`/`resume()`은 전투·타이머를 멈추고 재개한다. `setSpeed()`는 LOOP-05를 쓴다. `quit()`은 결과 화면으로 간다. `adReroll()`은 무료 리롤 1회, `adSupply()`는 보급 +5를 적용한다. (TECH §8)

### 판 밖 진행 (META)

- [ ] **META-01**: 한 판에서 웨이브 5에 도달하면 해금 순서(소총수·제설병·저격수 → 취사병 → 지뢰설치병)의 다음 카드 1종이 해금되어 `result()`의 `unlocked`로 전달된다. 상점은 해금된 카드만 뽑는다(`?unlock=all`이면 전부). (GDD §7)

### 측정 (LOG)

- [ ] **LOG-01**: 판마다 `run_start`, `wave_clear`, `run_end`, `card_buy`, `merge`, `unlock` 이벤트(GDD §11 파라미터)를 메모리에 모으고, 판이 끝나면 `localStorage`의 `d2_playlog`에 최근 50판까지 쌓는다. (GDD §11)
- [ ] **LOG-02**: `?scene=log`에서 `d2_playlog` 전체 판의 카드별 구매율과 평균 판 시간(+ 결과·도달 웨이브)을 볼 수 있다. G1 판정(구매율 5% 미만 카드 없음, 판당 6~10분)을 이 화면으로 한다. (GDD §11, TECH §9)

### 튜닝 (TUNE)

- [ ] **TUNE-01**: `data.ts`·`stages.ts` 수치만 조정해 브라우저에서 한 판이 6~10분 안에 끝나고, 처음 하는 사람도 웨이브 5에 도달할 수 있으며, 카드 5종 모두 살 이유가 있는 상태로 G1 플레이테스트(P 티켓)에 넘긴다. 바꾼 수치와 이유는 GDD 갱신용 메모로 남긴다. (GDD §1.2, `docs/ROADMAP.md` G1)
