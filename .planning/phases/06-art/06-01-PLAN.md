# 06-01: 실제 그림이 있으면 스프라이트, 없으면 지금 도형 (Claude가 직접 쓴 계획, CONTEXT 겸용)

> 우선순위: AGENTS.md > docs/ART.md(§2 규격, §4 계약) > docs/tickets/A-102-art-pack.md(코드가 만드는 것) > 이 계획.
> 브랜치 `kidariseok/m3-core`(main과 같음)에서 바로 한다. 레인 A 파일만 고친다. `src/assets.ts`(B)는 **import만** 한다(`ASSET_CONTRACTS`).
> 지금 실제 그림은 `public/assets/ally_rifle_idle.png`(2프레임 256×128)와 `ally_rifle_attack.png`(3프레임 384×128) 두 개뿐이다(`public/assets/index.json`). 앞으로 그림이 하나씩 들어오므로 **키 단위로 자동 교체**되게 만든다.

## 목표

전투 화면이 `public/assets/index.json`에 있는 키의 그림을 쓰고, 없는 키는 지금 도형 그대로 둔다. 피격·쓰러짐·계급·그림자는 코드가 그린다. `?art=0`이면 그림이 있어도 도형으로 그린다(비교용).

## 확정 결정

- **불러오기**(BattleScene `preload()`)
  1. `this.load.json(ART.indexKey, ART.indexUrl)`로 목록을 받는다.
  2. 그 파일이 끝나면(`filecomplete-json-<키>`) 목록의 키 중 `ASSET_CONTRACTS`에 있는 것만 `this.load.image(key, '/assets/<key>.png')`로 이어서 큐에 넣는다.
  3. 목록이 없거나 깨지면 조용히 빈 목록이다. `?art=0`이면 목록을 아예 받지 않는다.
  4. 실제 키 집합 `this.art: Set<string>`을 만든다. 텍스처가 실제로 로드된 키만 넣는다.
  - 플레이스홀더 텍스처는 만들지 않는다. `loadOrGenerateAssets`는 갤러리용이다.
- **프레임·애니메이션**(새 파일 `src/battle/art.ts`, 함수만, 클래스 없음)
  - `frameCount(imgW, contractW)` 순수 함수는 `rules.ts`에 둔다. 너비가 계약 너비의 배수가 아니면 0이다.
  - `setupArt(scene, keys)`가 키마다 텍스처에 프레임 0..n-1을 `texture.add(i, 0, i*w, 0, w, h)`로 만든다. 그다음 `scene.anims.create({ key, frames, frameRate: ART.fps[종류], repeat })`를 만든다.
    - 대기·걷기·달리기·가스(`_idle`, `_walk`, `_run`, `fx_gas`)는 반복한다.
    - 나머지(`_attack`, `_fire`, `_bite`, `fx_*`)는 1회다.
  - 수치(`fps`, 그림자 크기·투명도, 피격 틴트 시간, 쓰러짐 각도)는 `data.ts`의 `ART` 한 객체에 둔다.
- **아군 카드**(board.ts의 카드 컨테이너)
  - `ally_<card>_idle`이 있으면 사각형 몸통·머리글자 대신 스프라이트를 쓴다(대기 애니메이션 반복).
    - 발 피벗: `setOrigin(0.5, 116/128)`로 발끝을 칸 바닥 쪽에 둔다. 칸 안 위치는 기존 몸통 중심과 맞춘다.
  - 계급 표시(가로 작대기)와 HP 바는 그대로 둔다. 발밑 그림자는 반투명 타원으로 스프라이트 아래에 둔다.
  - 대기석 카드도 같은 컨테이너라 함께 바뀐다.
  - 이 카드가 공격하는 순간(units.ts 사격 경로) `ally_<card>_attack`이 있으면 1회 재생하고 끝나면 대기로 돌아간다. 없으면 지금처럼 둔다.
- **적**(enemies.ts)
  - 종류별 키: 보병 `enemy_inf_walk`·`_attack`, 군견·강화 군견 `enemy_dog_run`·`_bite`, RPG `enemy_rpg_walk`·`_fire`.
  - 걷기 키가 있으면 사각형 대신 스프라이트를 쓴다. 막혀서 공격할 때 공격 키를 1회 재생한다.
  - 강화 군견은 같은 그림에 기존 흰 테두리 대신 진한 틴트를 준다(`ART.dogPlusTint`).
  - 보스: `boss_apc_hull`이 있으면 몸체 스프라이트를 쓰고, `boss_apc_turret`이 있으면 그 위에 얹는다(회전 없음).
- **피격·쓰러짐**: 스프라이트일 때 피격은 `setTintFill(흰색)`을 `ART.hitMs` 동안 준다. 쓰러짐은 기존 `fall`(기울기 + 페이드)을 쓴다. 도형일 때는 지금 그대로 둔다.
- **이펙트**: `fx_muzzle`, `fx_explosion`, `fx_wind`, `fx_flame`, `fx_heal`, `fx_gas`가 있으면 해당 연출 함수(fx.ts)가 스프라이트 애니메이션을 1회 재생하고 지운다(가스 칸은 반복). 없으면 지금 도형 그대로 둔다. 지뢰 `mine`·`mine_at`도 같은 방식이다.
- **배경**: `bg_gate`가 있으면 판 뒤에 720×(화면 높이) 맞춤으로 깐다. 기존 판 칸 선은 그 위에 반투명으로 남긴다.
- **`?art=0`**: `new URLSearchParams(location.search)`로 직접 읽는다(`// ponytail: 게이트 때 debug.ts로`).
- 숫자·한글은 `src/battle/*.ts`에 두지 않는다(기존 게이트). 키 이름 문자열은 `data.ts`의 `ART.keys` 함수나 표에서 만든다.
