## 확정 결정

- **수치**(`data.ts`, 새 객체 `SUPPORT`): `charges: 2`, `damage: 200`, `delay: 1.0`(초, 예고선 뒤 포격), `pickSec: 5`(열 고르기 제한 초). 강조·예고선 색과 투명도는 기존 `UI.colors`·`UI.fx`에 더한다(붉은 계열은 적·경보 전용이라 예고선은 붉게, 열 강조는 노랑).
- **상태**(BattleScene 필드, 클래스·상태 머신 없이 변수로)
  - `support`: 판 시작 때 `SUPPORT.charges`. `resetRun`·재시작에서 초기화.
  - `picking`: 남은 초(0이면 고르는 중 아님).
  - `strikes`: `{ col, left }[]`. 포격 예약이다.
- **`fireSupport()`**
  - 동작 조건: `phase === 'fight'`, 결과 전, `support > 0`, `picking === 0`일 때만. 아니면 아무것도 안 한다.
  - 하는 일: `picking = SUPPORT.pickSec`로 두고, 5열 강조 사각형을 그리고, board 입력을 잠근다.
- **열 고르기**
  - 순수 함수 `colAt(x: number): number`(rules.ts)로 x를 열 0~4로 바꾼다. 판 밖은 -1이다. 기준은 `LAYOUT.left`·`LAYOUT.cell`·5열이다.
  - BattleScene의 `pointerdown`에서 `picking > 0`이면 `pickColumn(colAt(p.worldX))`를 부른다.
  - `pickColumn(col)`
    - `col < 0`이면 취소한다(횟수 유지).
    - 아니면 `support -= 1`을 하고, `strikes`에 `{ col, left: SUPPORT.delay }`를 넣고, 그 열에 붉은 예고선을 그린다. 그다음 강조를 지우고 입력 잠금을 푼다.
  - 헤드리스가 부를 수 있게 `pickColumn`은 public이다.
- **board 입력 잠금**: `board.ts`에 `lock(on: boolean)` 한 줄짜리를 더한다. 잠긴 동안 board의 pointerdown·dragstart가 바로 return한다. 열을 누르다가 카드를 집지 않게 하려는 것이다.
- **시간**: `update`의 `dt`(배속·일시정지 반영)로 `picking`과 `strikes[].left`를 줄인다. `setTimeout`·`time.delayedCall`은 쓰지 않는다(배속·일시정지와 어긋남).
  - `picking`이 0이 되면 취소한다(횟수 유지).
  - `left ≤ 0`인 포격을 실행한다.
- **포격 실행**
  - 그 열의 살아 있는(`!gone`, hp > 0) 적 전체에 `SUPPORT.damage`를 준다. 보스도 같다. 기존 적 피해 경로를 그대로 써서 처치 수·쓰러짐·기록이 맞게 한다.
  - 연출: 열 전체 `explosion` 여러 개(적 진입 구역 위쪽부터 배치 구역 아래까지 칸마다 1개)와 `shake(scene, 'heavy')`.
  - 기록: `fire_support { wave, col, kills }`. `LogEvent` 유니온에 더한다.
- **전투가 끝나면**(정산 진입, 결과): `picking = 0`(횟수 유지), 강조 제거, 입력 잠금 해제. 남은 `strikes`는 바로 실행하지 않고 버린다. 이미 줄어든 횟수는 돌려주지 않는다(1초 안에 웨이브가 끝나는 드문 경우).
- **HUD**: `h.support = this.support`를 넘긴다. hudKey 비교에 `support`를 넣는다. `bindBattle`에 `fireSupport: () => this.fireSupport()`를 더한다.
- **디버그**: `?support=N`이면 시작 횟수를 N으로 둔다. `new URLSearchParams(location.search)`로 직접 읽는다(`// ponytail: 게이트 때 debug.ts로`). `?gas=`와 같은 방식이다.
- **데프콘 1(DEF-01)**: 웨이브 7 전투 시작의 `ui.banner(..., 'defcon')` 바로 뒤에 `shake(this, 'heavy')`를 더한다. 테두리 점멸·소리는 T-104(B)가 이미 한다. 캔버스 테두리는 만들지 않는다(중복).
- **`?scene=log`(FIRE-02)**
  - `summarizeLog`에 `supportAvg`(판당 평균 `fire_support` 수)를 더한다. 테스트로 증명한다.
  - `log.ts`의 요약 줄에 "화력 지원 평균 n.n회"를 더한다. 문구는 data.ts의 `UI.text`에 둔다.
